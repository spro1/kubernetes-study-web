# Pulling Images from a Private Registry

A Pod asks for an image the registry will not hand out to strangers. Follow **Pod → kubelet → runtime → registry** and see where the login comes from, why it goes missing, and which error tells you what.

## Pull errors and what they mean

| Event message or reason | Cause | Fix |
|---|---|---|
| `401 Unauthorized`, `unauthorized`, `authorization failed` | No credentials, or wrong ones, for this registry | Check the Secret's server name matches the image's registry exactly; check user and token |
| `FailedToRetrieveImagePullSecret` | The named pull secret is not in the Pod's namespace | Create the Secret in that namespace, or fix the name |
| `manifest unknown`, `not found` | The name or tag does not exist (or no image for this CPU architecture) | Fix the image name or tag; check the registry UI |
| `403 Forbidden`, `denied` | Logged in, but this account may not read this repository | Grant pull access to the account or token |
| `429 Too Many Requests`, `toomanyrequests` | Registry rate limit, often anonymous Docker Hub pulls per IP | Log in for pulls, use a pull-through cache, or mirror the image |
| `i/o timeout`, `no such host` | Network, DNS, proxy or firewall from the node | Test from the node, e.g. `crictl pull`, and check egress |
| `x509: certificate signed by unknown authority` | The node does not trust the registry's certificate | Install the CA on the node or in the runtime's registry config |

## Try it yourself

```bash
kubectl create secret docker-registry regcred -n shop \
  --docker-server=registry.example.com \
  --docker-username=robot-pull --docker-password="$TOKEN"         # type kubernetes.io/dockerconfigjson
kubectl get secret regcred -n shop -o jsonpath='{.data.\.dockerconfigjson}' | base64 -d   # check the server name
kubectl patch serviceaccount default -n shop \
  -p '{"imagePullSecrets":[{"name":"regcred"}]}'                  # new Pods get it automatically
kubectl get pod web -n shop -o jsonpath='{.spec.imagePullSecrets}{"\n"}'   # what the Pod actually got
kubectl describe pod web -n shop | grep -A8 Events                 # read the Failed message
kubectl get events -A --field-selector reason=FailedToRetrieveImagePullSecret   # secret missing in a namespace
```
