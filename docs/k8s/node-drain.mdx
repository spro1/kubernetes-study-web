## Common misconceptions about upgrades

| Misconception | Reality |
| --- | --- |
| You can jump straight to the latest version | Minor versions go up one step at a time |
| Drain moves Pods with zero downtime | It deletes them and recreates them elsewhere; a single replica means an outage |
| A PDB protects you against node failure | A PDB only applies to voluntary maintenance like drain |
| If the engine upgrade succeeds, apps are fine | Deployments using APIs removed in the new version fail on their next deploy |
