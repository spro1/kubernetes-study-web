## Rolling update settings at a glance

| Setting | Meaning | If increased |
| --- | --- | --- |
| `maxSurge` | How many pods may briefly exist above the desired count | Finishes faster, but needs more spare resources |
| `maxUnavailable` | How many pods may briefly be missing below the desired count | Finishes faster, but capacity drops for a while |
| `readinessProbe` | Checks whether a new pod may receive requests | Without it, pods get requests as soon as they start, which can cause errors |
