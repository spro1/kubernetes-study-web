## Symptoms and where to look

| Symptom | Suspect | Where to look |
| --- | --- | --- |
| Traffic that worked suddenly times out | A new policy now selects the target Pod | `POD-SELECTOR` in `kubectl get networkpolicy` vs the target Pod’s labels |
| Every external call fails with "name not found" | Egress is blocked and DNS (port 53) was not opened | Egress rules in `kubectl describe networkpolicy` |
| The policy has no effect at all | No Pod matches the selector, or the network plugin does not support policies | Compare the policy’s Pod selector with the Pod labels |

## Try it yourself

```bash
kubectl get networkpolicy -n <namespace>             # POD-SELECTOR of each policy
kubectl describe networkpolicy <name> -n <namespace>   # Allowed Ingress and Egress
kubectl get pods -n <namespace> -l app=backend --show-labels   # Pods the selector matches
kubectl get pods -n kube-system -l k8s-app=cilium    # Is the enforcing CNI (Cilium) running?
```
