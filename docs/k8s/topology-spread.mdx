# Spreading Pods Across Zones (Topology Spread Constraints)

Six replicas in one zone survive no zone outage. Follow the scheduler as **topologySpreadConstraints** count Pods per zone and per node, refuse placements that tip the balance, and run into a dead zone and a rolling update.

## Fields at a glance

| Field | What it does | Watch out |
|---|---|---|
| `topologyKey` | Node label whose values form domains (`topology.kubernetes.io/zone`, `kubernetes.io/hostname`) | Nodes without the label are skipped entirely |
| `maxSkew` | Largest allowed gap between a domain and the global minimum | Must be at least 1 |
| `whenUnsatisfiable` | `DoNotSchedule` (default) filters nodes. `ScheduleAnyway` only scores | DoNotSchedule can leave Pods Pending during an outage |
| `labelSelector` | Which Pods are counted, same namespace only | The Pod should match its own selector, or it does not count itself |
| `matchLabelKeys` | Adds this Pod's values for these label keys to the selector, e.g. `pod-template-hash` | Do not use labels that get edited on running Pods |
| `minDomains` | Treat the global minimum as 0 until this many domains exist | Only with `DoNotSchedule` |
| `nodeAffinityPolicy` | `Honor` (default): only nodes matching the Pod's node affinity count | `Ignore` counts all nodes |
| `nodeTaintsPolicy` | `Ignore` (default): taints do not matter. `Honor`: skip nodes with untolerated taints | Default counts tainted nodes as domains |

## Try it yourself

```bash
kubectl get nodes -L topology.kubernetes.io/zone          # Which zone each node is in
kubectl explain pod.spec.topologySpreadConstraints        # Fields your cluster version supports

# Pods per zone for app=web
for n in $(kubectl get pods -l app=web -o jsonpath='{.items[*].spec.nodeName}'); do
  kubectl get node "$n" -o jsonpath='{.metadata.labels.topology\.kubernetes\.io/zone}{"\n"}'
done | sort | uniq -c

kubectl get pods -l app=web --field-selector=status.phase=Pending
kubectl describe pod <pending-pod>                        # "didn't match pod topology spread constraints"
kubectl get deploy web -o jsonpath='{.spec.template.spec.topologySpreadConstraints}'
```
