## Find where it stopped by the symptom

| Symptom in the app | Where it stopped | Common causes |
| --- | --- | --- |
| Name not found (host not found) | DNS lookup | Typo in the Service name, calling a Service in another namespace by its short name |
| Name lookup fails with no response, but the IP works | DNS server | CoreDNS outage, a network policy blocking DNS (port 53) lookups |
| Name resolves but connection fails | Service → pod | Selector and pod labels do not match so there are 0 target pods, port mismatch |
