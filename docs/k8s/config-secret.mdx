## Environment variables vs file mounts

| | Environment variables | File mount |
| --- | --- | --- |
| When the app reads it | Once, at program start | Whenever it reads the file at the given path |
| When the ConfigMap/Secret changes | Takes effect only after the Pod restarts | The file updates automatically after a delay; the app must re-read it |
| Good for | A few short values | Whole config files, certificates |
