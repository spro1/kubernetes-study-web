## Status and where it stopped

| Status in kubectl get | Step it stopped at | Common causes |
| --- | --- | --- |
| Pending | 4. Pick node | Not enough node resources, no node matches the placement rules |
| ImagePullBackOff | 6. Image | Typo in image name or tag, registry auth or access failure |
| CrashLoopBackOff | After 7. Run | Container keeps exiting right after start (config or code error) |

## Try it yourself

```bash
kubectl create deployment try-nginx --image=nginx --replicas=3   # Throwaway Deployment
kubectl get rs -l app=try-nginx                      # ReplicaSet the controller created
kubectl get pods -l app=try-nginx -o wide -w         # Pending → ContainerCreating → Running
kubectl describe pod <pod>                           # Events: Scheduled, Pulling, Started
kubectl delete deployment try-nginx                  # Clean up
```
