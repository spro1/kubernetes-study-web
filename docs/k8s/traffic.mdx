## What to check when you cannot connect

| Order | What to check | Common causes |
| --- | --- | --- |
| 1 | Does the domain point to the load balancer address? | DNS not registered, load balancer address changed |
| 2 | Are the Ingress rule host and path correct? | Typo, rule conflict with another Ingress |
| 3 | Do the Service labels and ports match? | Label mismatch leaves 0 target pods |
| 4 | Is at least one pod Ready? | Readiness probe failing, all pods restarting |

## Try it yourself

```bash
kubectl get ingress -A                               # HOSTS and load balancer ADDRESS
kubectl describe ingress <name>                      # Host and path → Service rules
kubectl get svc <service> -o wide                    # SELECTOR and ports
kubectl get endpointslices -l kubernetes.io/service-name=<service> -o yaml   # conditions.ready per Pod
kubectl get pods -o wide                             # READY column per Pod
```
