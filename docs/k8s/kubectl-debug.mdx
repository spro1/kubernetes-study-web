# Debugging a Running Pod with kubectl debug

A Pod misbehaves, and its image has no shell. Follow **kubectl exec → ephemeral container → Pod copy → node debugging Pod** and see what each one can reach, what it needs, and what it leaves behind.

## Which way to debug

| Situation | Use | What it can see | What stays behind |
|---|---|---|---|
| Container runs and has a shell | `kubectl exec -it <pod> -- sh` | Everything inside that container | Nothing |
| Container runs, image has no shell (distroless) | `kubectl debug -it <pod> --image=busybox:1.36 --target=<container>` | Pod network; with `--target`, the container's processes and `/proc/<pid>/root` | A Terminated ephemeral container until the Pod is replaced |
| Container crashes at startup | `kubectl logs <pod> --previous`, then `kubectl debug <pod> -it --copy-to=<name> --container=<c> -- sh` | A copy of the Pod with a new command or image (`--set-image`) | The copy Pod, until you delete it |
| Need to call the app from your laptop | `kubectl port-forward pod/<pod> 8080:8080` | One port of the Pod's network | Nothing after you stop it |
| Node problem (disk, network, processes) | `kubectl debug node/<node> -it --image=ubuntu` | Host PID, network and IPC namespaces; host files at `/host` | The node-debugger Pod, until you delete it |
| `Forbidden ... pods/ephemeralcontainers` | Grant `patch`, `update` on `pods/ephemeralcontainers` | — | — |

## Try it yourself

```bash
kubectl run demo --image=registry.k8s.io/pause:3.10 --restart=Never   # an image with no shell
kubectl exec -it demo -- sh                                # fails: no sh in the image
kubectl debug -it demo --image=busybox:1.36 --target=demo  # ephemeral container; try: ps
kubectl get pod demo -o jsonpath='{.spec.ephemeralContainers[*].name}{"\n"}'   # it stays in the spec
kubectl debug demo -it --copy-to=demo-debug --image=busybox:1.36 --share-processes   # copy with a debug container
kubectl debug node/$(kubectl get pod demo -o jsonpath='{.spec.nodeName}') -it --image=ubuntu   # try: ls /host
kubectl auth can-i patch pods/ephemeralcontainers         # do you have the permission?
kubectl get pods | grep -E 'debug|node-debugger'          # leftovers
kubectl delete pod demo demo-debug                        # clean up (and the node-debugger-... Pod)
```
