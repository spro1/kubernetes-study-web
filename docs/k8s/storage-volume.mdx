## Symptoms by the stage that stopped

| Stage that stopped | What kubectl get shows | Where to look |
| --- | --- | --- |
| 3. Create disk | PVC stays `Pending` | PVC events — StorageClass name typo, provisioner not installed, out of capacity, unsupported access mode |
| 6. Attach to node | Pod stays in `ContainerCreating` | `FailedAttachVolume` in pod events — often the volume is still attached to another node |
| 6. Mount | Pod stays in `ContainerCreating` | `FailedMount` in pod events — permissions, file system errors, NFS server unreachable |
