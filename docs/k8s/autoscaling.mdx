## When the HPA does not behave as expected

| Symptom | What to check |
| --- | --- |
| Usage shows as `<unknown>` | Whether metrics-server is running, and whether the Pods declare resource requests |
| Desired Pods went up but the Pod is Pending | Free resources on nodes, namespace quota |
| Load dropped but Pods stay | Whether the scale-in stabilization window has passed, the minimum replica count |
