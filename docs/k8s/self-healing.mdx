## Self-healing by failure level

| What stopped | Who revives it | Result | Time taken |
| --- | --- | --- | --- |
| Container | That node's kubelet | Container restarts inside the same pod | Seconds (up to 5 min apart if repeated) |
| Node | Controllers + scheduler | New pod created on another node | Minutes (includes the default 5 min wait) |
| Pod deleted manually | ReplicaSet controller | New pod created | Seconds |

## Try it yourself

```bash
kubectl get pods -o wide                             # RESTARTS and node per Pod
kubectl logs <pod> --previous                        # Logs from the last run
kubectl describe pod <pod>                           # Last State and Back-off events
kubectl get nodes                                    # NotReady nodes
kubectl get pod <pod> -o jsonpath='{.spec.tolerations}'   # not-ready wait (300s by default)
```
