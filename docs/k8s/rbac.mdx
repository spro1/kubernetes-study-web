## The four parts of RBAC

| Name | What it does | Scope |
| --- | --- | --- |
| `Role` | A set of permissions: which actions (get·list·delete, etc.) are allowed on which resources | One namespace |
| `ClusterRole` | The same kind of permission set, but can also cover cluster-scoped resources such as nodes | Cluster |
| `RoleBinding` | Binds a permission set to users, groups, or ServiceAccounts | One namespace |
| `ClusterRoleBinding` | Binds a ClusterRole across the whole cluster | Cluster |

## Try it yourself

```bash
kubectl auth whoami                                  # Who authentication says you are
kubectl get rolebindings -n <namespace> -o wide      # Which Role is bound to whom
kubectl auth can-i delete pods -n <namespace> --as <user>   # no means 403 Forbidden
kubectl auth can-i list pods -n <namespace> --as system:serviceaccount:<namespace>:<sa>   # Same check for a ServiceAccount
kubectl auth can-i list nodes                        # Cluster-scoped, needs a ClusterRole
```
