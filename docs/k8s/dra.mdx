# Requesting GPUs by Criteria (DRA)

Until now, Kubernetes could only request GPUs by count. **Dynamic Resource Allocation (DRA)** lets you request them **by criteria**, such as "one GPU with at least 40 GB of memory". The core API became GA in Kubernetes 1.34. Follow how a request turns into a device.

## Device plugins vs DRA

| | Before (device plugin) | DRA |
| --- | --- | --- |
| How you request | Count only (`nvidia.com/gpu: 1`) | Class + criteria (e.g. at least 40 GB of memory) |
| Device info | Node only reports "how many" | Driver publishes each device with its attributes |
| Who picks | The node’s device plugin, any device | The scheduler, picking a matching device and recording it |
| Status in Kubernetes | Still widely used | Core API GA in 1.34; extra features graduate in later versions |
