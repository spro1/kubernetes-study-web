## Placement rules at a glance

| Rule | Direction | What it does | Example |
| --- | --- | --- | --- |
| Requests (`requests`) | Scheduler filters nodes | Drops nodes without room for the summed requests | Requests 1 CPU core → node with 0.5 free is excluded |
| Taints · tolerations | Node filters pods | Accepts only pods that tolerate the mark | Keep regular pods off GPU nodes |
| Node selector · node affinity | Pod chooses nodes | Goes only to nodes with matching labels | Only nodes with `gpu: "true"` |
| Pod anti-affinity | Pod avoids other pods | Puts replicas of the same app on different nodes | One web replica per node |
