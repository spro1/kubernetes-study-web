# All Lessons

Flows that are confusing to read become clear in **diagrams that move one step at a time**. Each lesson takes about 10 minutes. Every time you press **Next**, components appear and requests flow. Turn on **▶ Auto-play** to sit back and watch it like a video.

New here? Go from the top in order. Already familiar? Pick the flow you are curious about.

## How to Use the Lessons

| Action | How |
| --- | --- |
| Next / previous step | Buttons in the right panel, or click the lesson area once, then <kbd>←</kbd> <kbd>→</kbd> |
| Jump to a step | The numbers on the step timeline below |
| Auto-play | The **▶ Auto-play** button above the diagram, or <kbd>A</kbd> |
| Replay / pause animation | Buttons above the diagram, or <kbd>R</kbd> · <kbd>P</kbd> |
| Line colors | Blue = request, purple = response / report, dashed teal = watch |

If "Reduce motion" is on in your system settings, you see only lines and descriptions, without moving dots.
