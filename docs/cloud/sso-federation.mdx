# Single Sign-On for People (SSO and Federation)

An engineer needs the cloud console, a Kubernetes cluster and a few internal apps. Follow how one **identity provider** (IdP) becomes the only place their account lives, and how every other system trusts it instead of keeping its own users. How a single OIDC login works is in [How Logging In Works (Sessions, JWT, OIDC)](../basic/auth-login.mdx); how a cloud API checks a request is in [Permission Checks on One API Request (IAM)](../cloud/iam-request.mdx).

## SAML or OIDC

| | SAML 2.0 | OpenID Connect |
|---|---|---|
| Built on | XML, signed assertions | OAuth 2.0, signed JWT (ID token) |
| How it travels | Browser posts the assertion to the service | Redirect with a code, tokens fetched by the client |
| Typical users | Cloud consoles, enterprise SaaS | Web and mobile apps, CLIs, kubectl |
| Works without a browser | Hard | Yes, with the device flow or a local redirect |
| Provisioning users ahead of login | Neither does it. Use SCIM | Neither does it. Use SCIM |

When someone leaves: disable them in the IdP (stops new logins everywhere), check that SCIM disabled them downstream, revoke sessions in sensitive systems, and look for anything outside SSO such as IAM users, local accounts or personal access tokens.

## Try it yourself

```bash
aws configure sso                                  # Set up a profile: start URL, account, permission set
aws sso login --profile dev                        # Opens the browser, signs in at the IdP
aws sts get-caller-identity --profile dev          # ARN shows assumed-role/AWSReservedSSO_...
aws sso-admin list-instances                       # Identity Center instance and identity store ID
aws sso-admin list-permission-sets --instance-arn <instance-arn>
aws identitystore list-groups --identity-store-id <store-id>   # Groups synced from the IdP by SCIM
aws iam generate-credential-report && aws iam get-credential-report \
  --query Content --output text | base64 --decode | cut -d, -f1,4,9,10   # Leftover IAM users and active keys
kubectl oidc-login setup --oidc-issuer-url=https://login.example.com --oidc-client-id=kubernetes   # kubelogin plugin
kubectl auth whoami                                # Username and groups from the token
```
