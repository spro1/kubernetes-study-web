# How Object Storage Works

A shop app saves product photos to object storage and shows them to users. This lesson uses Amazon S3 as the example. Google Cloud Storage, Azure Blob Storage and MinIO work the same way under different names. Follow one photo from upload to archive, and see who is allowed to read it at each step.

## Block, file and object storage

| | Block storage | File storage | Object storage |
|---|---|---|---|
| Examples | Amazon EBS, Persistent Disk, Azure Disk | Amazon EFS, Filestore, Azure Files, NFS | Amazon S3, Cloud Storage, Azure Blob, MinIO |
| How you use it | Mounted as a disk on one server, with a file system on top | Mounted as a shared folder by many servers | HTTP API (PUT, GET, DELETE, LIST) |
| Unit | Blocks | Files in directories | Whole objects under flat keys |
| Change part of the data | Yes | Yes | No, replace the whole object |
| Shared by many clients | Usually one node at a time | Yes | Yes, over the network from anywhere |
| In Kubernetes | PersistentVolume (ReadWriteOnce) | PersistentVolume (ReadWriteMany) | Called from the app, or mounted through a CSI driver with limits |
| Good for | Databases, boot disks | Shared files for legacy apps | Images, backups, logs, data sets, model files |

## Try it yourself

```bash
aws s3 ls s3://shop-images/photos/                         # List a prefix (a "folder")
aws s3 cp ./123.jpg s3://shop-images/photos/123.jpg        # Upload (multipart is used automatically for big files)
aws s3api head-object --bucket shop-images --key photos/123.jpg   # Size, ETag, storage class, VersionId
aws s3 presign s3://shop-images/photos/123.jpg --expires-in 600   # Temporary URL, valid 10 minutes
aws s3api get-public-access-block --bucket shop-images     # Is public access blocked?
aws s3api get-bucket-versioning --bucket shop-images       # Enabled / Suspended / (empty = never enabled)
aws s3api list-object-versions --bucket shop-images --prefix photos/123.jpg   # Versions and delete markers
aws s3api list-multipart-uploads --bucket shop-images      # Unfinished uploads you are still paying for
```
