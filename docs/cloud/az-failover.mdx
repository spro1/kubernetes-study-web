## Failure-handling names (AWS · Azure · GCP)

| Concept | AWS | Azure | GCP |
| --- | --- | --- | --- |
| Availability zone | Availability Zone | Availability Zone | Zone |
| Load balancer health check | Target group health check | Health probe | Health check |
| Primary/standby DB across zones | RDS Multi-AZ deployment | Zone-redundant high availability (Flexible Server) | Cloud SQL high availability (regional instance) |
