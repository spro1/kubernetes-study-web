# Infrastructure as Code with Terraform

Clicking through a cloud console works once. It is hard to review, hard to repeat and easy to forget. With infrastructure as code (IaC), you write the servers and firewalls you want in files and let a tool make the cloud match. Follow **code → init → plan → apply → state** with Terraform. OpenTofu, an open-source fork, uses the same files and commands (`tofu` instead of `terraform`). The network being built here is explained in [How a Request Travels Inside a VPC](../cloud/vpc-request.mdx).

## Reading plan symbols

| Symbol | Action | Meaning |
|---|---|---|
| `+` | create | The resource is in the code but not in the state. It will be created |
| `-` | destroy | The resource is in the state but no longer in the code. It will be deleted |
| `~` | update in place | Some attributes change on the existing object. Its ID stays the same |
| `-/+` | replace | Destroy first, then create a new object. Look for `# forces replacement` |
| `+/-` | replace (create first) | `create_before_destroy` is set: the new object is created before the old one is deleted |
| `<=` | read | A data source is read during apply because it depends on values not known yet |

The last line of every plan sums it up: `Plan: X to add, Y to change, Z to destroy.` Check Z before anything else.

## Try it yourself

```bash
terraform init                      # Download providers, set up the backend
terraform fmt -check && terraform validate   # Style and syntax
terraform plan -out=tfplan          # Diff code vs state vs cloud, save the plan
terraform show tfplan               # Review the saved plan
terraform apply tfplan              # Apply exactly that plan
terraform plan -refresh-only        # Only show drift from changes made outside Terraform
terraform state list                # Resources Terraform manages
terraform state show aws_instance.web   # Recorded attributes and real ID
terraform destroy                   # Delete everything in the state (asks first)
# OpenTofu: the same commands with tofu instead of terraform
```
