## Myths and facts

| Myth | Fact |
| --- | --- |
| A Pending PVC means something is broken | With WaitForFirstConsumer it is normal until a Pod appears |
| Local volumes are fast, so always better | On node failure, the Pod cannot move to another node |
| When a node dies, the volume attaches elsewhere at once | RWO waits for confirmation it was detached from the old node |
| RWO means only one Pod can use it | It means one node. Several Pods on that node can share it |
| You can shrink volume size later | It can only grow |
| With snapshots you do not need backups | Snapshots live on the same system and can be lost with it |

## Try it yourself

```bash
kubectl get storageclass                                 # VOLUMEBINDINGMODE and ALLOWVOLUMEEXPANSION
kubectl describe pvc <name> -n <namespace>               # Events: normal wait or failure?
kubectl get pvc -n <namespace>                           # Access modes and capacity
kubectl get pv <pv> -o jsonpath='{.spec.nodeAffinity}'   # Local volume tied to one node
kubectl get volumeattachments                            # Which node an RWO volume is attached to
kubectl get volumesnapshotclass                          # Can snapshots work here?
```
