# kube-proxy Modes, from Service IP to Pod IP

The packet lesson showed that a Service IP becomes a Pod IP on the sending node. Here we open that box: what kube-proxy writes into the kernel in each mode, how eBPF datapaths do the same job, and what conntrack and traffic policy change.

## The modes side by side

| | iptables | IPVS | nftables | eBPF replacement (e.g. Cilium) |
|---|---|---|---|---|
| Status | Default today | Deprecated since v1.35, removal planned | GA since v1.33, kernel 5.13+ | Outside Kubernetes, from the CNI |
| Service lookup | Walks `KUBE-SERVICES` rules | Hash table of virtual servers | Verdict map | eBPF map |
| Endpoint choice | Random, `statistic --probability` | Scheduler: `rr`, `lc`, `sh` and others | Random | Chosen at `connect()` or per packet at tc/XDP |
| Updates | Large table rewrites | Per virtual server | Only what changed | Map updates |
| Where to look | `iptables-save -t nat` | `ipvsadm -Ln` | `nft list table ip kube-proxy` | CNI tools, e.g. `cilium-dbg service list` |

## Try it yourself

```bash
# Which mode? (on a node; kind nodes: docker exec -it lab-worker bash)
curl -s localhost:10249/proxyMode                     # kube-proxy metrics port answers iptables / ipvs / nftables
kubectl logs -n kube-system ds/kube-proxy | grep -i proxier   # e.g. "Using iptables Proxier"
kubectl get endpointslices -l kubernetes.io/service-name=web  # the endpoints kube-proxy programs

# iptables mode
iptables-save -t nat | grep -E 'KUBE-SVC|KUBE-SEP' | head     # chains and probability rules
iptables-save -t nat | grep -c KUBE-SEP                        # how many endpoint rules on this node

# nftables and IPVS mode
nft list table ip kube-proxy | less                   # maps and per-Service chains
ipvsadm -Ln                                           # virtual servers and real servers

# conntrack
conntrack -L -d 10.96.12.34                           # flows to this ClusterIP and their DNAT target
conntrack -D -p udp --orig-dst 10.96.0.10             # clear stale UDP entries to kube-dns by hand
```
