# Keeping Secrets Safe

A Kubernetes Secret keeps a password out of the image, but by itself it does not keep the password safe. Follow one DB password from `kubectl apply` into etcd, out to readers, into Git, and finally into an external vault that rotates it. How a Secret reaches a Pod as an env var or a file is covered in [Config and Secrets](../k8s/config-secret.mdx).

## Ways to handle secrets compared

| Approach | Where the value lives | In Git | Rotation |
|---|---|---|---|
| Plain Secret | etcd (plain unless encrypted at rest) | Plain base64 if committed: avoid | Manual `kubectl apply` |
| Sealed Secrets | etcd, after the controller decrypts | Ciphertext (SealedSecret) | Re-seal and commit a new value |
| SOPS | etcd, after decrypt at deploy time | Ciphertext values | Re-encrypt and commit |
| External Secrets Operator | External vault, copied into a Secret | Only a reference (ExternalSecret) | In the vault, picked up every `refreshInterval` |
| Secrets Store CSI Driver | External vault, mounted as a file (Secret optional) | Only a reference (SecretProviderClass) | In the vault, file refreshed if rotation is enabled |
| Dynamic credentials | Issued per request by the vault | Nothing | Automatic, each credential expires |

## Try it yourself

```bash
kubectl create secret generic db-pass --from-literal=password=s3cr3t
kubectl get secret db-pass -o jsonpath='{.data.password}' | base64 -d   # base64 is not encryption

# Lab cluster only, on a control plane node: read the raw etcd value
sudo ETCDCTL_API=3 etcdctl --endpoints=https://127.0.0.1:2379 \
  --cacert=/etc/kubernetes/pki/etcd/ca.crt --cert=/etc/kubernetes/pki/etcd/server.crt \
  --key=/etc/kubernetes/pki/etcd/server.key \
  get /registry/secrets/default/db-pass | hexdump -C | head   # s3cr3t visible, or k8s:enc:… if encrypted

kubectl auth can-i list secrets -n default --as=system:serviceaccount:default:default   # should be "no"
kubectl get secrets -A -o json | kubectl replace -f -    # rewrite all Secrets after enabling encryption
kubectl get externalsecret -A                            # STATUS SecretSynced, REFRESH INTERVAL
kubectl get clustersecretstore,secretstore -A            # Can the operator reach the vault?
```
