# Practice exams

These sets check whether you understand the concepts behind each certification. Every question is multiple choice, shows the answer and the reason as soon as you pick, and is grouped by the official exam domain so you can see where you are weak.

| Set | Exam format | Questions |
| --- | --- | --- |
| [KCNA practice questions](./kcna.mdx) | Multiple choice, 90 minutes | 21 |
| [CKA practice questions](./cka.mdx) | Hands-on in a terminal, 2 hours | 24 |
| [CKAD practice questions](./ckad.mdx) | Hands-on in a terminal, 2 hours | 25 |
| [CKS practice questions](./cks.mdx) | Hands-on in a terminal, 2 hours | 27 |

## How to use them

- **KCNA** is a multiple-choice exam, so these questions are close to the real format.
- **CKA, CKAD and CKS** are performance-based: you fix and build things in a live cluster with `kubectl` and the official docs open. Knowing the right answer here is only half of it. You also need to type it fast. Pair each set with the [Hands-on labs](../labs/index.mdx) and keep the [Command cheat sheet](../cheatsheet.mdx) open while you practice.
- When you miss a question, open the lessons in the **Study:** line under that domain. The [Learning paths & certifications](../roadmap.mdx) page maps every exam domain to its lessons.

All questions are original and unofficial. They are not taken from any real exam, and the real exams can change with each Kubernetes release, so check the official curriculum before you book.
