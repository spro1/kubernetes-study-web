# CKAD practice questions

The CKAD is a 2-hour hands-on exam in a terminal, based on Kubernetes v1.37. It has five domains:

| Domain | Weight | Questions here |
| --- | --- | --- |
| Application Environment, Configuration and Security | 25% | 6 |
| Application Design and Build | 20% | 5 |
| Application Deployment | 20% | 5 |
| Services and Networking | 20% | 5 |
| Application Observability and Maintenance | 15% | 4 |

The questions are original and unofficial, not taken from the real exam. Domains and weights come from the official curriculum, as listed on [Learning paths & certifications](../roadmap.mdx). The real exam asks you to write and fix manifests, so practice the commands in the [Hands-on labs](../labs/index.mdx).

## Application Design and Build (20%)

  {q: 'You need a log-shipping container that starts before the app, keeps running beside it and does not block a Job from completing.   {q: 'A Pod shows STATUS Init:0/1 for several minutes.   {q: 'Two containers in the same Pod must share files that only live as long as the Pod.
