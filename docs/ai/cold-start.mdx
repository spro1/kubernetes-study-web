# Until a Model First Starts (Cold Start)

A typical web Pod starts in seconds. An LLM replica must read **model weights** that can exceed tens of GB, load them into accelerator memory, and prepare the engine, which can take minutes. The time from creating a replica until it can take its first request is the **cold start**. The general Pod startup path is in [How a Pod Starts](../k8s/pod-startup.mdx); this lesson focuses on the parts that get long because it is an LLM.

## What to check per phase

| Phase | Where to look | How to shorten |
| --- | --- | --- |
| Image pull | Pod events (Pulling, Pulled) | Pre-pull images, nearby registry |
| Weight fetch | Engine logs, network usage | Local model cache |
| Load to accelerator | Load time in engine logs | NVMe, GPUDirect Storage |
| Engine warm-up | Warm-up time in engine logs | Reuse compile cache, compile ahead |
