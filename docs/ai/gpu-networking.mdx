# Moving Data Between GPUs

Distributed training stops to exchange gradients at every step, so the network between GPUs sets the pace. Follow the data from one GPU to another, first inside a node and then across nodes, and see how Kubernetes hands an RDMA NIC to a Pod.

## Symptoms and causes

| Symptom | Likely cause | Check |
|---|---|---|
| NCCL log shows `NET/Socket` | No RDMA device in the Pod, or `NCCL_IB_DISABLE=1` | `ibv_devinfo` inside the Pod, resource requests, Multus annotation |
| RDMA device present, NCCL still fails to register memory | Memory cannot be pinned | `IPC_LOCK` capability, `ulimit -l` in the container |
| `NET/IB` but no `GDRDMA` | GPUDirect RDMA not enabled, or GPU and NIC far apart | nvidia-peermem or DMA-BUF support, `nvidia-smi topo -m` |
| RoCE works at low load, collapses at scale | PFC or ECN not set the same on all hops | Pause and ECN counters on NICs and switches |
| RoCE connections fail or hang | Wrong GID index or RoCE version | `NCCL_IB_GID_INDEX`, GID table of the device |
| Intra-node all-reduce slow | No NVLink path, traffic crosses sockets | `nvidia-smi topo -m`, `nvidia-smi nvlink --status` |
| One slow node drags the whole job | Bad cable, link down to lower speed, or a degraded port | `ibstat` or `ethtool` link speed, per-node all_reduce_perf |

## Try it yourself

```bash
nvidia-smi topo -m                 # NV# = NVLink, PIX/PXB = same PCIe switch, SYS = across CPU sockets
ibv_devinfo                        # RDMA devices, state PORT_ACTIVE, link_layer InfiniBand or Ethernet
kubectl get network-attachment-definitions -A          # secondary networks Multus can attach
kubectl get node gpu-node-1 -o jsonpath='{.status.allocatable}'   # GPU and RDMA resources
kubectl exec trainer-0 -- ip -br addr                  # eth0 from the primary CNI, net1 from Multus

# RDMA bandwidth between two Pods (perftest), using GPU memory on both ends
kubectl exec trainer-0 -- ib_write_bw -d mlx5_0 --use_cuda=0 -a              # server
kubectl exec trainer-1 -- ib_write_bw -d mlx5_0 --use_cuda=0 -a 10.10.0.11   # client, server net1 IP

# NCCL all-reduce across 2 nodes x 8 GPUs (nccl-tests built with MPI=1)
mpirun -np 16 -N 8 -x NCCL_DEBUG=INFO -x NCCL_DEBUG_SUBSYS=INIT,NET \
  ./build/all_reduce_perf -b 8 -e 8G -f 2 -g 1 2>&1 | grep -E 'NET/|busbw|GDRDMA'
```
