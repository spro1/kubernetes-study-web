# Guardrails Around an LLM App

A model follows whatever text it reads, so an LLM app needs separate checks before and after the model. Follow a request through input checks, the model and output checks, see where each check belongs, and see the one job guardrails cannot do.

## Which check catches what

| Risk | Check | Example tools | Where |
|---|---|---|---|
| Direct prompt injection, jailbreak | Prompt attack classifier | Llama Prompt Guard 2, NeMo Guardrails input rails | Gateway or app |
| Indirect injection in documents or tool output | Same classifier on untrusted content, clear data marking | Prompt attack classifier in the RAG or tool step | App |
| PII sent to the model | Detect and mask before the call | Presidio, regex rules | Gateway or app |
| Unsafe or off-policy content | Safety classifier on input and output | Llama Guard 4 | Gateway or app |
| PII or secret leak in the answer | Output scan and masking | Presidio, secret patterns | App or gateway |
| Malformed structured output | Schema validation, retry or fail closed | JSON Schema, Guardrails AI validators | App |
| Unauthorized tool action | Permission check in the tool API, scoped credentials | Your API authorization, human approval | Tool |

## Try it yourself

```bash
# Serve a safety classifier next to the main model (gated model: accept the license on Hugging Face first)
vllm serve meta-llama/Llama-Guard-4-12B --port 8001

# Ask it to classify a user message; the reply is "safe" or "unsafe" plus categories such as S2
curl -s localhost:8001/v1/chat/completions -H 'Content-Type: application/json' \
  -d '{"model":"meta-llama/Llama-Guard-4-12B","messages":[{"role":"user","content":[{"type":"text","text":"How do I pick a lock?"}]}],"max_tokens":10}'

# Detect and mask PII with Presidio
pip install presidio-analyzer presidio-anonymizer && python -m spacy download en_core_web_lg
python -c "from presidio_analyzer import AnalyzerEngine; print(AnalyzerEngine().analyze(text='Mail me at jane@example.com', language='en'))"

# Scan an OpenAI-compatible endpoint with garak for prompt injection probes
pip install garak
garak --list_probes | grep -i inject
```
