# Under One Request: TCP/IP Layers

[When You Type an Address](../basic/web-request.mdx) showed a request going from the browser to a server. This lesson opens that arrow. Follow one connection to `203.0.113.10:443` through the **TCP/IP layers**: what each layer adds, which address it uses, and where it breaks.

## Layers, units and addresses

| TCP/IP layer | OSI layer | Unit | Address | Example tool |
|---|---|---|---|---|
| Application | 7 (5–7) | Message (HTTP request) | URL, host name | `curl -v` |
| Transport | 4 | Segment (TCP) | Port | `ss -tlnp` |
| Internet | 3 | Packet | IP address | `ip route`, `traceroute` |
| Link | 2 (and 1) | Frame | MAC address | `ip neigh`, `tcpdump -e` |

## Refused or timed out?

| Symptom | What happened | Check |
|---|---|---|
| `Connection refused`, instantly | Host replied RST: nothing listens on that port and address | `ss -tlnp` on the server. Is the app up, on the right port, bound to `0.0.0.0` and not only `127.0.0.1`? |
| `Connection timed out`, after a long wait | SYN got no answer: dropped on the path | Firewall rules, security groups, routes (`traceroute`) |
| `No route to host` | A router or firewall sent back an ICMP error, or ARP for the next hop got no answer | `ip route`, `ip neigh`, the host is up |
| Connects, then large responses hang | Path MTU smaller than the packets, and the ICMP that would say so is blocked | `ping -M do -s 1472 <host>`, tunnel MTU, MSS clamping |

## Try it yourself

```bash
ip route                                   # default via <gateway> — where off-subnet traffic goes
ip neigh                                   # ARP / neighbor cache: IP → MAC on this LAN
traceroute -n <host>                       # each router hop (uses TTL expiry)
ss -tlnp                                   # listening TCP sockets and the process holding each (run on the server)
curl -v http://<host>:8080/                # "Connected to" vs "Connection refused" vs timeout
sudo tcpdump -ni any 'tcp port 443 and tcp[tcpflags] & (tcp-syn|tcp-rst) != 0'   # watch SYN, SYN-ACK and RST
```
