# Writing a Good Dockerfile

## Line by line: common mistake and better habit

| Line | Common mistake | Better | Why |
|---|---|---|---|
| `COPY` | `COPY . .` before installing dependencies | Copy lockfiles, install, then copy source | A code edit no longer reinstalls everything |
| `.dockerignore` | Missing | Exclude `.git`, dependency folders, build output, `.env` | Smaller context, stable cache, no leaked files |
| `FROM` | One stage on a full SDK image | Build stage plus a slim or distroless runtime stage | Toolchain and source stay out of the image |
| `FROM` | Floating tag like `node:22` | `image:tag@sha256:...`, updated by a bot | Same commit builds the same image |
| `USER` | None (root) | Numeric non-root UID | Works with `runAsNonRoot`, smaller blast radius |
| `CMD` / `ENTRYPOINT` | Shell form `CMD node server.js` | Exec form `CMD ["node", "server.js"]` | SIGTERM reaches the app, rollouts stop cleanly |
| `ARG` / `ENV` / `COPY` | Token passed or copied in | `RUN --mount=type=secret` | Secret never lands in a layer or metadata |
| `HEALTHCHECK` | Relied on in Kubernetes | Readiness, liveness and startup probes | The kubelet does not run HEALTHCHECK |

## Try it yourself

```bash
docker build -t my-app:dev .                                  # uses BuildKit by default
docker history my-app:dev                                     # every layer, its size and the line that made it
docker image inspect my-app:dev \
  --format 'user={{.Config.User}} entrypoint={{json .Config.Entrypoint}} cmd={{json .Config.Cmd}}'
docker buildx imagetools inspect gcr.io/distroless/static-debian12:nonroot   # digest to pin in FROM
docker build --secret id=npmrc,src=$HOME/.npmrc -t my-app:dev .              # pair with RUN --mount=type=secret,id=npmrc
docker build --build-arg SOURCE_DATE_EPOCH=$(git log -1 --pretty=%ct) -t my-app:dev .   # fixed timestamps
kubectl debug -it pod/my-app --image=busybox:1.36 --target=app # shell next to a distroless container
```
