## Find the failing step from the symptom

| Symptom | Failing step | What to check |
| --- | --- | --- |
| Site cannot be found | DNS · connection | Check name resolution with `nslookup`, check access to the internal network |
| "Not secure" warning | Encryption (certificate) | Check for an expired certificate, a domain mismatch, or a private certificate |
| Page loads but the list is empty | Data request (API) | Check the API response status code in the browser developer tools |
| 401 / 403 | Response | 401: check credentials (login, token). 403: check permission settings |
| 504 | Response (timeout) | Check backend response time and health. The request may actually have been processed |
| Broken fonts or slow page rendering | Air-gapped network | Check for external CDN resources and host them internally |

## Try it yourself

```bash
dig +short <domain>                                  # Step 2: name to IP address
nc -zv <domain> 443                                  # Step 3: is port 443 reachable?
curl -v -o /dev/null https://<domain>/               # Connect, certificate, request, status code
curl -s -o /dev/null -w '%{http_code} %{time_total}s\n' https://<domain>/   # Status code and response time
```
