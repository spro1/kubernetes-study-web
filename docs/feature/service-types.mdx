## Try it yourself

```bash
kubectl get svc shop-svc -o wide                       # TYPE, CLUSTER-IP, EXTERNAL-IP, PORT(S), SELECTOR
kubectl get pods -l app=shop --show-labels             # Are there pods matching the selector?
kubectl get endpointslices -l kubernetes.io/service-name=shop-svc   # Are target pod addresses non-empty?
kubectl get svc shop-svc -o yaml                       # type, selector, ports, sessionAffinity
```
