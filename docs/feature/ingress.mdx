## Try it yourself

```bash
kubectl get ingressclass                             # Available handlers and the default class
kubectl get ingress shop -o wide                     # CLASS, HOSTS, ADDRESS
kubectl describe ingress shop                        # Backends per path and events
kubectl get endpointslices -l kubernetes.io/service-name=api   # Does the backend Service select pods?
kubectl get secret shop-tls -o jsonpath='{.type}'    # Is it kubernetes.io/tls?
```
