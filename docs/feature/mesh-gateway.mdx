## Try it yourself

```bash
kubectl get pods -n istio-system -l istio=ingressgateway       # Is the ingress proxy running?
kubectl get gateways.networking.istio.io -n shop -o yaml       # hosts, port, selector, tls
kubectl get virtualservice -n shop -o yaml                     # gateways, hosts, route destination
kubectl get namespace shop --show-labels                       # Is istio-injection=enabled set?
istioctl analyze -n shop                                       # Find broken links
```
