# Service Mesh ④ Ambient Mode Without Sidecars

Ambient mode moves the mesh proxy out of the Pod. A per-node **ztunnel** handles mTLS and identity at L4, and an optional **waypoint** proxy adds L7 features only where you ask for them. Watch what works with ztunnel alone, and what silently does not.

## What runs where

| Feature | Sidecar mode | Ambient, ztunnel only | Ambient with a waypoint |
|---|---|---|---|
| Join the mesh | Injection label, then restart the Pods | `istio.io/dataplane-mode=ambient`, no restart | Same, plus `istio.io/use-waypoint` |
| mTLS and workload identity | Sidecar | ztunnel (HBONE, port 15008) | ztunnel |
| AuthorizationPolicy on principals, namespaces, ports | Sidecar | ztunnel | ztunnel or waypoint |
| AuthorizationPolicy on methods, paths, headers | Sidecar | Not enforced: ALLOW denies all, DENY blocks nothing | Waypoint, attached with `targetRefs` |
| HTTPRoute, retries, timeouts, header routing | Sidecar | Ignored | Waypoint |
| VirtualService | Sidecar | Ignored | Waypoint (Alpha) |
| Metrics | L4 and L7 | L4 (TCP) only | L4 and L7 |
| Proxy count | One per Pod | One per node | One per node, plus waypoints |

## Try it yourself

```bash
kubectl label namespace shop istio.io/dataplane-mode=ambient   # Add the namespace to the mesh
kubectl get pods -n shop                                       # Still READY 1/1, no restarts
kubectl get daemonset ztunnel -n istio-system                  # One ztunnel per node
istioctl ztunnel-config workloads                              # PROTOCOL HBONE for meshed Pods
kubectl logs -n istio-system -l app=ztunnel | grep -E "inbound|outbound"   # Connections and identities
istioctl waypoint apply -n shop --enroll-namespace             # Create a waypoint and label the namespace
kubectl get gateways.gateway.networking.k8s.io -n shop        # waypoint, class istio-waypoint, PROGRAMMED
kubectl get namespace shop -L istio.io/dataplane-mode,istio.io/use-waypoint   # Which labels are on
kubectl get authorizationpolicy -n shop -o yaml                # selector (ztunnel) or targetRefs (waypoint)?
```
