# Service Mesh ① Sidecars and Mutual Authentication

This lesson uses Istio, a popular service mesh, as the example. Turn on one setting for a namespace, and without changing app code, traffic becomes **encrypted, identity-checked, and recorded**. Follow what happens behind the scenes.

## Try it yourself

```bash
kubectl label namespace shop istio-injection=enabled   # Enable automatic sidecar injection
kubectl get namespace -L istio-injection               # Which namespaces have it on
kubectl rollout restart deployment -n shop             # Recreate existing pods to attach sidecars
kubectl get pods -n shop                               # READY 2/2 means the proxy is attached
kubectl get peerauthentication -A                      # mTLS mode (PERMISSIVE, STRICT)
```
