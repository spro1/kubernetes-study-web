# Service Mesh ② Splitting Traffic

## Try it yourself

```bash
kubectl get destinationrule api -o yaml      # subsets, trafficPolicy (load balancing, connection limits)
kubectl get virtualservice api -o yaml       # match (headers), route weight, retries, timeout
kubectl edit virtualservice api              # Roll the weights back to 100 : 0
istioctl proxy-config routes deploy/web      # Actual rules the web-side proxy received
```
