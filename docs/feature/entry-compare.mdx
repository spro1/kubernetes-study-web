## Try it yourself

```bash
kubectl describe ingress -n shop                                  # Ingress: hosts, paths, and backends
kubectl get gateways.networking.istio.io,virtualservices -n shop  # Mesh path: gateway and VirtualService pair
kubectl get namespace shop --show-labels                          # Is istio-injection=enabled set?
kubectl get gatewayclass                                          # Gateway API controller
kubectl get gateways.gateway.networking.k8s.io,httproutes -n shop # Standard Gateway and routes
```
