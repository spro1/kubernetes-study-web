## Reading status.parents

Each entry in an HTTPRoute's `status.parents` matches one `parentRef` and holds the conditions written by that Gateway's controller.

| Condition | Reason | Meaning | Fix |
|---|---|---|---|
| Accepted=True | Accepted | The Gateway took the route | — |
| Accepted=False | NotAllowedByListeners | No listener's `allowedRoutes` permits this route (namespace or kind) | Change the listener's `allowedRoutes`, or label the route's namespace to match its selector |
| Accepted=False | NoMatchingListenerHostname | No listener hostname matches the route's `hostnames` | Align the route hostnames with the listener hostname (for example `*.example.com`) |
| Accepted=False | NoMatchingParent | `sectionName` or `port` in the parentRef matches no listener | Fix the parentRef to name an existing listener |
| Accepted=Unknown | Pending | The controller has not reconciled the route yet | Check that the GatewayClass is Accepted and the controller is running |
| ResolvedRefs=True | ResolvedRefs | All backendRefs could be resolved | — |
| ResolvedRefs=False | RefNotPermitted | A backendRef points to another namespace with no ReferenceGrant | Create a ReferenceGrant in the target namespace |
| ResolvedRefs=False | BackendNotFound | The referenced Service does not exist | Fix the name, namespace or port, or create the Service |
| ResolvedRefs=False | InvalidKind | The backendRef group or kind is unknown or unsupported | Point to a Service, or a kind the implementation supports |

If `status.parents` is empty, no controller has handled the route at all. Check the parentRef name and namespace, and the GatewayClass.

## Try it yourself

```bash
kubectl get gatewayclass                             # CONTROLLER and ACCEPTED
kubectl get gateway -A                               # CLASS, ADDRESS, PROGRAMMED
kubectl describe gateway infra-gw -n infra           # Listeners, allowedRoutes, attachedRoutes
kubectl get httproute -A                             # HOSTNAMES per route
kubectl get httproute store -n shop \
  -o jsonpath='{range .status.parents[*].conditions[*]}{.type}={.status} {.reason}{"\n"}{end}'   # Accepted / ResolvedRefs
kubectl get referencegrant -A                        # Who allows cross-namespace refs
```
