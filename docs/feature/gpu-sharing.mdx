# Sharing GPUs

GPUs are expensive, so keep them busy by sharing them. On Kubernetes, the NVIDIA GPU Operator lets you use one GPU **whole (Pass-through)**, **split by hardware partitions (MIG)**, or **split in time (Time-Slicing)**. Follow what each mode divides and what shows up in the metrics.

## Try it yourself

```bash
kubectl get pods -n gpu-operator                     # GPU Operator component status
kubectl describe node <gpu-node> | grep -i nvidia    # GPU resource name and count, MIG labels
kubectl get pods -A -o wide | grep -i gpu            # Which node each GPU pod runs on
```
