# Namespaces and Resource Quotas

When several teams share one cluster, Kubernetes **namespaces (partitions within a cluster)** and **resource quotas (per-namespace resource caps)** do the work. Follow along as you create partitions, set caps, and see a pod over the cap get rejected.

## Try it yourself

```bash
kubectl get namespaces
kubectl describe quota -n team-a          # Hard (cap) and Used (usage)
kubectl get limitrange -n team-a          # Default requests and limits
kubectl get events -n team-a | grep -i quota
kubectl auth can-i create resourcequotas -n team-a
```
