# Automatic Pod Sizing (VPA)

HPA changes the **number** of pods; VPA changes the **size** of each pod. Follow what happens behind the scenes when you attach a VPA to a workload.

## Try it yourself

```bash
kubectl get vpa -A                                   # Attached VPAs and their update modes
kubectl describe vpa <name>                          # Recommendation
kubectl get pod <pod> -o jsonpath='{.spec.containers[*].resources}'   # Actual pod values
kubectl get hpa -A                                   # Is an HPA attached to the same target?
```
