# Traffic Leaving the Cluster (Egress)

A payments Pod calls a partner API that only accepts known source IPs. Follow the packet out of the cluster: **Pod → node SNAT → NAT gateway → partner**. Then lock egress down with policies and give the traffic a fixed source IP.

## Ways to control egress

| Need | Tool | Matches on | Limits |
| --- | --- | --- | --- |
| Block all, open a few paths | NetworkPolicy egress | Pod and namespace labels, ipBlock CIDRs, ports | No hostnames; enforced only if the CNI supports policies |
| Allow by hostname | CNI extension, e.g. Cilium `toFQDNs` | DNS names learned from DNS answers | CNI-specific CRD; the Pod must resolve through the cluster DNS path |
| Fixed source IP for some Pods | Egress gateway, e.g. Cilium Egress Gateway | Selected Pods and destination CIDRs | Gateway nodes become a dependency; needs specific CNI features |
| Only declared external hosts, L7 view | Service mesh, e.g. Istio `REGISTRY_ONLY` + ServiceEntry + egress gateway | Hostnames, ports, protocols | Sidecar or proxy can be bypassed; pair with NetworkPolicy |
| One public IP for the whole VPC | Cloud NAT gateway | Route table | Every workload shares the IP |

## Try it yourself

```bash
# Which source IP does the outside world see?
kubectl run egress-test --rm -it --image=curlimages/curl --restart=Never -- curl -s https://ifconfig.me
kubectl get networkpolicy -n <namespace>                      # POD-SELECTOR and which policies exist
kubectl describe networkpolicy <name> -n <namespace>          # Allowing egress traffic: ports and ipBlock
kubectl get pods -n kube-system -l k8s-app=kube-dns --show-labels   # Labels the DNS rule must select
kubectl get ciliumnetworkpolicy -A                            # Cilium: toFQDNs rules
kubectl get ciliumegressgatewaypolicy                         # Cilium: egress gateway policies (cluster-scoped)
hubble observe --verdict DROPPED --traffic-direction egress   # Cilium Hubble: blocked outbound flows
kubectl get serviceentry -A                                   # Istio: declared external hosts
```
