# 주소창에 주소를 입력하면

## 증상으로 막힌 단계 찾기

| 보이는 증상 | 막힌 단계 | 확인할 것 |
| --- | --- | --- |
| 사이트를 찾을 수 없음 | DNS · 연결 | `nslookup`으로 이름 풀이 확인, 내부망 접속 여부 확인 |
| "안전하지 않음" 경고 | 암호화(인증서) | 인증서 만료·도메인 불일치·사설 인증서 여부 확인 |
| 페이지는 떴는데 목록이 비어 있음 | 데이터 요청(API) | 브라우저 개발자 도구에서 API 응답의 상태 코드 확인 |
| 401 / 403 | 응답 | 401은 인증 정보(로그인·토큰), 403은 권한 설정을 본다 |
| 504 | 응답(시간 초과) | 뒤쪽 서버의 응답 시간과 상태 확인. 요청이 실제로는 처리됐을 수도 있다 |
| 글꼴이 깨지거나 페이지가 늦게 그려짐 | 폐쇄망 | 외부 CDN 자원을 불러오는지 확인하고 내부에 둔다 |

더 읽을거리: [HTTP 개요 (MDN)](https://developer.mozilla.org/ko/docs/Web/HTTP/Overview) · [HTTP 상태 코드 (MDN)](https://developer.mozilla.org/ko/docs/Web/HTTP/Status) · [서비스 (쿠버네티스 문서)](https://kubernetes.io/ko/docs/concepts/services-networking/service/) · [서비스 및 파드용 DNS](https://kubernetes.io/ko/docs/concepts/services-networking/dns-pod-service/)
