# 개발자에게 필요한 암호 기초

암호 코드를 직접 짤 일은 드물지만 설정은 매일 한다. TLS, JWT, SSH 키, 서명된 이미지, KMS에 든 비밀값이 다 그렇다. 보내는 쪽에서 받는 쪽으로 가는 메시지 하나를 따라가며 어떤 도구가 무엇을 지키는지, 잘못 쓰면 어떻게 깨지는지 본다.

## 어떤 도구가 어떤 질문에 답하나

| 도구 | 무결성 | 기밀성 | 보낸 이 | 키 | 만나는 곳 |
|---|---|---|---|---|---|
| 해시(SHA-256) | 다이제스트를 믿을 수 있으면 예 | 아니오 | 아니오 | 없음 | 이미지 다이제스트, 파일 체크섬 |
| HMAC | 예 | 아니오 | 공유 키를 가진 누군가 | 공유 비밀 하나 | 웹훅 서명, JWT HS256, API 요청 서명 |
| AEAD(AES-GCM, ChaCha20-Poly1305) | 예 | 예 | 공유 키를 가진 누군가 | 공유 비밀 하나 | TLS 레코드, 디스크·DB 암호화, KMS 데이터 키 |
| 서명(Ed25519, ECDSA, RSA) | 예 | 아니오 | 개인키 주인, 누구나 확인 가능 | 개인키 서명, 공개키 검증 | JWT RS256/ES256, cosign, SSH, 인증서 |
| 키 교환(ECDHE) | — | 공유 키를 만든다 | 서명을 더해야 확인 | 쓰고 버리는 키 쌍 | TLS 1.3, SSH |
| 비밀번호 해시(Argon2id, scrypt, bcrypt) | 추측이 맞는지 확인 | — | — | 사용자별 솔트, 비용 설정 | 사용자 로그인 DB |

| 실수 | 무엇이 잘못되나 | 대신 할 것 |
|---|---|---|
| 직접 만든 방식이나 프로토콜 | 테스트로는 안 잡히는 미묘한 구멍 | 검증된 라이브러리의 고수준 API, 전송에는 TLS |
| ECB 모드 | 같은 블록이 같은 암호문이 되어 무늬가 샌다 | AEAD 모드(GCM) |
| GCM 논스 재사용 | 평문 XOR이 새고 태그를 위조할 수 있다 | 메시지마다 96비트 무작위 논스나 카운터, 키 교체 |
| 보안에 MD5나 SHA-1 | 충돌로 내용을 바꿔치기할 수 있다 | SHA-256 이상 |
| 비밀번호를 암호화하거나 빠른 해시로 저장 | 키가 새거나 GPU가 되살린다 | 솔트와 함께 Argon2id, scrypt, bcrypt |
| MAC을 `==`로 비교 | 몇 바이트 맞았는지 시간으로 샌다 | 상수 시간 비교 |

## 직접 확인해 보기

```bash
echo -n 'hello' | openssl dgst -sha256                    # 해시: 입력이 같으면 다이제스트도 같다
echo -n 'hello!' | openssl dgst -sha256                   # 한 글자만 바꿔도 전부 바뀐다
echo -n 'payload' | openssl dgst -sha256 -hmac 'secret'   # 공유 키로 HMAC

openssl genpkey -algorithm ed25519 -out key.pem           # 개인키
openssl pkey -in key.pem -pubout -out pub.pem             # 개인키에서 뽑은 공개키
echo 'release v1' > msg.txt
openssl pkeyutl -sign -inkey key.pem -rawin -in msg.txt -out msg.sig                  # 개인키로 서명
openssl pkeyutl -verify -pubin -inkey pub.pem -rawin -in msg.txt -sigfile msg.sig     # 공개키로 검증

openssl s_client -connect example.com:443 -tls1_3 </dev/null 2>/dev/null | grep -iE 'cipher|temp key|group'   # AEAD 암호와 키 교환 그룹(X25519, 또는 하이브리드 X25519MLKEM768)
ssh-keygen -t ed25519 -f ./demo_key -N '' && ssh-keygen -lf ./demo_key.pub   # SSH 키 쌍과 SHA256 지문
htpasswd -nbBC 12 alice 'correct horse'                  # bcrypt 해시, 비용 12 ($2y$12$...)
```
