# 서버 한 대에서 컨테이너까지

## 물리 서버·가상 머신·컨테이너 비교

| 구분 | 무엇을 따로 갖나 | 특징 |
| --- | --- | --- |
| 물리 서버 | 하드웨어와 운영체제 전체 | 한 대에 프로그램 하나만 올리면 자원이 남는다 |
| 가상 머신 | 자기만의 운영체제 | 하이퍼바이저가 자원을 나눠 주고 격리한다. 운영체제를 통째로 가져 무겁다 |
| 컨테이너 | 프로그램과 라이브러리만 | 커널을 함께 쓴다. 수 초 안에 시작되고 같은 서버에 훨씬 많이 올린다 |

이렇게 만든 컨테이너의 원본(이미지)이 어디서 오는지는 다음 레슨에서, 컨테이너가 노드에서 실제로 시작되는 과정은 [파드가 뜨기까지](../k8s/pod-startup.mdx)에서 본다.
