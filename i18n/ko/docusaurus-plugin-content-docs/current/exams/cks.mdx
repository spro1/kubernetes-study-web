# CKS 모의 문제

CKS는 쿠버네티스 v1.37 기준으로 터미널에서 2시간 동안 푸는 실기 시험이고, CKA를 먼저 따야 볼 수 있다. 영역은 여섯 개다.

| 영역 | 비중 | 여기 문제 수 |
| --- | --- | --- |
| Cluster Setup | 15% | 4 |
| Cluster Hardening | 15% | 4 |
| System Hardening | 10% | 4 |
| Minimize Microservice Vulnerabilities | 20% | 5 |
| Supply Chain Security | 20% | 5 |
| Monitoring, Logging and Runtime Security | 20% | 5 |

문제는 직접 만든 비공식 문제이고 실제 시험에서 가져온 것이 아니다. 영역과 비중은 [학습 경로와 자격증](../roadmap.mdx)에 정리한 공식 커리큘럼을 따른다. 실제 시험은 살아 있는 클러스터를 직접 단단하게 만드는 시험이니 [장애 실습](../labs/index.mdx)에서 손에 익힌다.
