# 자격증 모의 문제

각 자격증의 바탕이 되는 개념을 제대로 알고 있는지 확인하는 문제 모음이다. 모두 객관식이고, 보기를 고르면 바로 정답과 이유가 나온다. 공식 시험 영역별로 묶었으니 어느 영역이 약한지 바로 보인다.

| 문제 모음 | 시험 형식 | 문제 수 |
| --- | --- | --- |
| [KCNA 모의 문제](./kcna.mdx) | 객관식, 90분 | 21 |
| [CKA 모의 문제](./cka.mdx) | 터미널 실기, 2시간 | 24 |
| [CKAD 모의 문제](./ckad.mdx) | 터미널 실기, 2시간 | 25 |
| [CKS 모의 문제](./cks.mdx) | 터미널 실기, 2시간 | 27 |

## 이렇게 쓴다

- **KCNA**는 객관식 시험이라 여기 문제가 실제 형식과 가깝다.
- **CKA·CKAD·CKS**는 실기 시험이다. 공식 문서를 띄워 놓고 실제 클러스터에서 `kubectl`로 고치고 만든다. 정답을 아는 것은 절반일 뿐이고, 그것을 빨리 입력할 수 있어야 한다. 문제 모음마다 [장애 실습](../labs/index.mdx)을 함께 하고, 연습하는 동안 [명령어 치트시트](../cheatsheet.mdx)를 열어 둔다.
- 틀린 문제가 있으면 그 영역 아래 **공부할 레슨:** 줄의 레슨을 연다. [학습 경로와 자격증](../roadmap.mdx) 페이지에 시험 영역별 레슨이 모두 정리돼 있다.

모든 문제는 직접 만든 비공식 문제다. 실제 시험에서 가져온 것이 아니고, 실제 시험은 쿠버네티스 릴리스마다 바뀔 수 있으니 응시 전에 공식 커리큘럼을 확인한다.
