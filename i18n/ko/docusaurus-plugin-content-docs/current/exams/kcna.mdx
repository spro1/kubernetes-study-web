# KCNA 모의 문제

KCNA는 90분짜리 객관식 시험이고 영역은 네 개다.

| 영역 | 비중 | 여기 문제 수 |
| --- | --- | --- |
| Kubernetes Fundamentals | 44% | 6 |
| Container Orchestration | 28% | 6 |
| Cloud Native Application Delivery | 16% | 5 |
| Cloud Native Architecture | 12% | 4 |

문제는 직접 만든 비공식 문제이고 실제 시험에서 가져온 것이 아니다. 영역과 비중은 [학습 경로와 자격증](../roadmap.mdx)에 정리한 공식 커리큘럼을 따른다.
