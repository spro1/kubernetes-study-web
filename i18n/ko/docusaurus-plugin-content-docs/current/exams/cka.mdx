# CKA 모의 문제

CKA는 쿠버네티스 v1.37 기준으로 터미널에서 2시간 동안 푸는 실기 시험이고 영역은 다섯 개다.

| 영역 | 비중 | 여기 문제 수 |
| --- | --- | --- |
| Troubleshooting | 30% | 6 |
| Cluster Architecture, Installation and Configuration | 25% | 5 |
| Services and Networking | 20% | 5 |
| Workloads and Scheduling | 15% | 4 |
| Storage | 10% | 4 |

문제는 직접 만든 비공식 문제이고 실제 시험에서 가져온 것이 아니다. 영역과 비중은 [학습 경로와 자격증](../roadmap.mdx)에 정리한 공식 커리큘럼을 따른다. 실제 시험은 고르는 게 아니라 직접 해내야 하니 [장애 실습](../labs/index.mdx)에서 명령을 손에 익힌다.
