# 가상 머신 자동 증감 (오토스케일링 그룹)

쇼핑몰이 가상 머신 두 대로 돌고 있다. 요청이 몰리면 가상 머신을 자동으로 늘리고, 고장 난 것은 바꾸고, 한가해지면 줄이는 장치가 오토스케일링 그룹이다. 같은 일을 파드 단위로 하는 HPA는 [부하에 맞춰 늘어나기 (HPA)](../k8s/autoscaling.mdx)에서 다룬다. 여기서는 그보다 한 층 아래, 서버(가상 머신) 수가 늘고 주는 흐름을 본다.

## 오토스케일링 그룹 이름 (AWS · Azure · GCP)

| 개념 | AWS | Azure | GCP |
| --- | --- | --- | --- |
| 자동 증감하는 VM 묶음 | Auto Scaling group | Virtual Machine Scale Sets | 관리형 인스턴스 그룹 (MIG) |
| VM 설계도 | 시작 템플릿 (launch template) | 스케일 세트의 VM 모델 | 인스턴스 템플릿 |
| 헬스 체크 실패 VM 교체 | 헬스 체크 기반 교체 | 자동 인스턴스 복구 | 자동 복구 (autohealing) |

더 읽을거리: [Amazon EC2 Auto Scaling (AWS)](https://docs.aws.amazon.com/autoscaling/ec2/userguide/what-is-amazon-ec2-auto-scaling.html) · [노드 오토스케일링 (쿠버네티스 문서)](https://kubernetes.io/docs/concepts/cluster-administration/node-autoscaling/) · [부하에 맞춰 늘어나기 (HPA)](../k8s/autoscaling.mdx)
