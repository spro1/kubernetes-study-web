# 누가 어디까지 맡나 (IaaS·PaaS·SaaS)

회사 전산실에서 돌던 웹 서비스 하나를 클라우드로 옮긴다. 어떤 방식으로 옮기느냐에 따라 우리 팀이 직접 챙겨야 하는 일이 크게 달라진다. 서비스를 여섯 계층으로 나눠, 책임 경계가 어디로 움직이는지 따라가 본다.

## 방식별 책임 경계 한눈에

| 운영 방식 | 우리가 관리 | 사업자가 관리 | 예 (AWS · Azure · GCP) |
| --- | --- | --- | --- |
| 온프레미스 | 하드웨어부터 데이터까지 전부 | 없음 | 회사 전산실·데이터센터 |
| IaaS | 운영체제·런타임·앱·데이터 | 하드웨어·가상화 | EC2 · Virtual Machines · Compute Engine |
| PaaS | 앱·데이터 | 하드웨어·가상화·운영체제·런타임 | Elastic Beanstalk · App Service · App Engine |
| SaaS | 데이터·계정·권한 | 앱까지 전부 | Microsoft 365 · Google Workspace 같은 업무용 서비스 |
