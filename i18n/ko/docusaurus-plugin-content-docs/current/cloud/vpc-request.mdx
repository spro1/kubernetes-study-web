# VPC 안에서 요청이 가는 길

클라우드에 올린 쇼핑몰에 사용자가 접속한다. 요청은 클라우드 안의 내 전용 네트워크(VPC)로 들어와 여러 관문을 지난다. 무엇이 인터넷에 드러나 있고 무엇이 숨어 있는지, 각 관문이 무엇을 통과시키고 막는지 따라가 본다. 데이터센터 안에서 요청이 가는 기본 흐름은 [주소창에 주소를 입력하면](../basic/web-request.mdx)에서 먼저 볼 수 있다.

## 관문별 이름 (AWS · Azure · GCP)

| 개념 | AWS | Azure | GCP |
| --- | --- | --- | --- |
| 내 전용 네트워크 | VPC | Virtual Network (VNet) | VPC network |
| 인터넷 출입문 | Internet Gateway | 별도 자원 없이 기본 인터넷 경로 | 기본 인터넷 게이트웨이 경로 |
| 나가는 길 전용 주소 변환 | NAT Gateway | NAT Gateway | Cloud NAT |
| 서버 앞 상태 유지 방화벽 | Security Group | Network Security Group (NSG) | VPC 방화벽 규칙 |
| 로드밸런서 | Elastic Load Balancing | Load Balancer · Application Gateway | Cloud Load Balancing |
