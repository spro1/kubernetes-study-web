# 공개 엔드포인트 지키기 (WAF와 DDoS)

쇼핑몰 공개 사이트에 진짜 사용자, 봇넷, SQL 인젝션을 찔러 보는 공격자가 한꺼번에 들어온다. 어느 계층이 어떤 트래픽을 막는지 따라간다. 네트워크 폭주는 제공자 엣지가, 나쁜 HTTP 요청은 **WAF**(웹 애플리케이션 방화벽)가 막고, 아무도 이를 돌아가지 못하게 오리진을 잠근다.

## 어느 계층이 어떤 공격을 막나

| 공격 | 계층 | 막는 것 | 예 |
|---|---|---|---|
| SYN 플러드, UDP 반사, DNS 증폭 | L3/L4 | 제공자 엣지, 애니캐스트, 네트워크 DDoS 보호 | AWS Shield, Azure DDoS Protection, Google Cloud Armor, Cloudflare |
| 비싼 페이지에 대한 HTTP 폭주 | L7 | WAF 비율 기반 규칙, 챌린지·CAPTCHA, CDN 캐시 | `/search` 로 범위를 좁힌 비율 기반 규칙 |
| SQL 인젝션, XSS, 경로 탐색 | L7 | 관리형 규칙 세트, 그리고 앱의 안전한 코드 | 핵심 규칙 세트, SQL 인젝션 규칙 |
| 알려진 공격 페이로드 | L7 | 알려진 악성 입력 규칙 세트 | Log4j류 헤더 |
| 크리덴셜 스터핑, 스크래핑 봇 | L7 | 봇 제어, 로그인 비율 제한 | 봇 제어 규칙 그룹 |
| 서비스하지 않는 지역의 트래픽 | L7 | 지역 일치 규칙(차단 또는 챌린지) | 국가 허용 목록 |
| 오리진으로 곧장 보낸 요청 | 네트워크 | CDN·WAF에만 열어 둔 오리진 | CDN 프리픽스 목록, 비밀 헤더, 사설 오리진 |

## 직접 확인해 보기

```bash
aws wafv2 list-web-acls --scope REGIONAL --region us-east-1      # 로드밸런서용 웹 ACL (CDN은 CLOUDFRONT)
aws wafv2 list-available-managed-rule-groups --scope REGIONAL --region us-east-1   # 붙일 수 있는 관리형 규칙
aws wafv2 get-web-acl --name shop-acl --id <acl-id> --scope REGIONAL --region us-east-1 \
  --query 'WebACL.Rules[].{name:Name,prio:Priority,action:Action,override:OverrideAction}'   # 규칙마다 카운트인지 차단인지
aws wafv2 get-rate-based-statement-managed-keys --scope REGIONAL --region us-east-1 \
  --web-acl-name shop-acl --web-acl-id <acl-id> --rule-name search-rate   # 지금 비율 제한에 걸린 IP
aws wafv2 get-logging-configuration --resource-arn <acl-arn> --region us-east-1   # 로그가 어딘가로 가고 있나
curl -s -o /dev/null -w '%{http_code}\n' -G https://shop.example.com/ --data-urlencode "id=1' OR '1'='1"   # 403이 나와야 한다
curl -s -o /dev/null -w '%{http_code}\n' --max-time 5 https://<origin-lb-dns-name>/   # 오리진 잠금: 타임아웃이나 403이어야 한다
aws ec2 describe-managed-prefix-lists --filters Name=prefix-list-name,Values=com.amazonaws.global.cloudfront.origin-facing   # 오리진 방화벽에 넣을 CDN 범위
```
