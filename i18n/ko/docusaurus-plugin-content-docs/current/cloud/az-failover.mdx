# 가용 영역 하나가 멈추면

쇼핑몰의 서버와 DB를 한 리전(region, 사업자가 데이터센터를 모아 둔 지역) 안의 두 가용 영역에 나눠 두었다. 그중 한 영역이 통째로 멈추는 날, 무엇이 자동으로 일어나고 무엇을 잃는지 따라가 본다.

## 장애에 대비하는 이름 (AWS · Azure · GCP)

| 개념 | AWS | Azure | GCP |
| --- | --- | --- | --- |
| 가용 영역 | Availability Zone | Availability Zone | Zone |
| 로드밸런서의 상태 확인 | 대상 그룹 헬스 체크 | 상태 프로브 (health probe) | 헬스 체크 |
| 영역을 나눈 주·대기 DB | RDS 다중 AZ 배포 | 영역 중복 고가용성 (Flexible Server) | Cloud SQL 고가용성 (리전 인스턴스) |
