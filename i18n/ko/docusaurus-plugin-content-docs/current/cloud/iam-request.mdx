# API 요청 하나의 권한 검사 (IAM)

배포 스크립트가 클라우드에 "이 파일을 저장소에 올려 줘"라고 요청한다. 클라우드는 요청 하나하나마다 "누구인가", "그 일을 해도 되는가"를 따진다. 이 검사를 IAM(Identity and Access Management, 신원·접근 관리)이 맡는다. 쿠버네티스 안에서 같은 일을 하는 RBAC는 [누가 무엇을 할 수 있나 (RBAC)](../k8s/rbac.mdx)에서 다룬다.

## 권한 검사에 쓰이는 이름 (AWS · Azure · GCP)

| 개념 | AWS | Azure | GCP |
| --- | --- | --- | --- |
| 신원과 권한 관리 | IAM | Microsoft Entra ID · Azure RBAC | Cloud IAM |
| 프로그램이 맡는 신원 | IAM 역할 (STS로 임시 자격 증명) | 관리 ID (Managed Identity) | 서비스 계정 |
| 조직 전체에 거는 거부 | 서비스 제어 정책 (SCP) | 거부 할당 (deny assignment) | IAM 거부 정책 |
| API 호출 기록 | CloudTrail | 활동 로그 (Activity Log) | Cloud Audit Logs |

더 읽을거리: [IAM이란 무엇인가 (AWS)](https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html) · [정책 평가 로직 (AWS)](https://docs.aws.amazon.com/IAM/latest/UserGuide/reference_policies_evaluation-logic.html) · [누가 무엇을 할 수 있나 (RBAC)](../k8s/rbac.mdx)
