# 매니지드 데이터베이스가 대신 해 주는 일

매니지드 데이터베이스는 엔진·OS·하드웨어를 클라우드 제공자에게 맡긴다. Amazon RDS for PostgreSQL 인스턴스 하나를 따라 **장애 조치, 복원, 유지 관리, 연결 폭주**를 지나가며(Cloud SQL과 Azure Database도 거의 같다), 여전히 내 몫인 일이 무엇인지 본다.

## 누가 무엇을 하나

| 일 | 제공자 | 나 |
|---|---|---|
| 하드웨어, OS, 엔진 설치 | 돌리고 패치한다 | 인스턴스 클래스와 엔진 버전을 고른다 |
| 고가용성 | 대기 인스턴스를 두고, 고장을 감지하고, DNS를 바꾼다 | 다중 AZ를 켜고, 앱이 다시 접속하고 재시도하게 만든다 |
| 읽기 확장 | 복제본을 만들고 변경을 보낸다 | 읽기를 복제본 엔드포인트로 보내고 지연을 다룬다 |
| 백업 | 매일 스냅샷, 로그, 특정 시점 복원 | 보존 기간을 정하고, 복원 연습을 하고, 복원 뒤 앱 접속처를 바꾼다 |
| 유지 관리 | 기간 안에 패치와 마이너 버전을 적용한다 | 기간을 고르고, 메이저 업그레이드(블루/그린)를 계획한다 |
| 설정 | 파라미터 그룹을 준다 | 내 그룹을 만들고, 정적 파라미터는 재부팅한다 |
| 연결 | 메모리로 max_connections를 정하고 프록시를 준다 | 풀 크기를 잡고, RDS Proxy나 PgBouncer 같은 프록시를 둔다 |
| 스토리지와 암호화 | 한도까지 스토리지를 늘리고 KMS로 암호화한다 | 최대치를 정하고, 만들 때 암호화를 켠다 |
| 스키마, 쿼리, 인덱스 | — | 모두 내 몫 |

이름만 다르다. Google Cloud SQL은 다중 AZ를 "고가용성(리전 인스턴스)"이라 부르고 데이터베이스 플래그로 설정한다. Azure Database for PostgreSQL 유연한 서버는 "영역 중복 고가용성"이라 부르고 서버 매개변수로 설정한다.

## 직접 확인해 보기

AWS CLI 예시다.

```bash
aws rds describe-db-instances --db-instance-identifier mydb \
  --query 'DBInstances[].[Endpoint.Address,MultiAZ,AvailabilityZone,SecondaryAvailabilityZone,StorageEncrypted,MaxAllocatedStorage]'
dig +short mydb.xxxx.ap-northeast-2.rds.amazonaws.com             # 엔드포인트 CNAME이 지금 가리키는 곳
aws rds reboot-db-instance --db-instance-identifier mydb --force-failover   # 장애 조치 연습 (스테이징에서!)
aws rds describe-events --source-identifier mydb --source-type db-instance --duration 60   # failover started / completed
aws rds describe-db-instances --db-instance-identifier mydb \
  --query 'DBInstances[].[LatestRestorableTime,BackupRetentionPeriod,PreferredBackupWindow,PreferredMaintenanceWindow]'
aws rds restore-db-instance-to-point-in-time --source-db-instance-identifier mydb \
  --target-db-instance-identifier mydb-restored --restore-time 2026-11-27T05:02:00Z \
  --db-parameter-group-name my-pg17                                # 엔드포인트가 따로 있는 새 인스턴스
aws rds describe-pending-maintenance-actions                      # 필수·선택 업데이트
aws rds describe-db-parameters --db-parameter-group-name my-pg17 \
  --query "Parameters[?ParameterName=='max_connections']"         # 흔히 메모리 기반 수식
```

```sql
SHOW max_connections;
SELECT count(*), state FROM pg_stat_activity GROUP BY state;     -- 누가 연결을 쥐고 있나
```
