# GPU·NPU가 노드 자원이 되기까지 (디바이스 플러그인)

쿠버네티스는 처음부터 CPU와 메모리만 안다. 서버에 GPU나 NPU를 꽂아도 그것만으로는 파드가 가속기를 요청할 수 없다. 장치를 쿠버네티스 자원으로 알려 주는 것이 **디바이스 플러그인**이다. 장치가 노드 자원이 되고 파드에 붙기까지 따라가 본다.

## 디바이스 플러그인과 DRA 비교

| 구분 | 디바이스 플러그인 | DRA |
| --- | --- | --- |
| 요청 방법 | 개수만 (`nvidia.com/gpu: 1`) | 장치 종류 + 속성 조건 |
| 노드가 알리는 정보 | 자원 이름별 장치 수와 상태 | 장치별 속성이 담긴 목록(ResourceSlice) |
| 장치를 고르는 곳 | 노드의 kubelet | 스케줄러 |
| 나눠 쓰기 | 노드 쪽 설정(MIG, Time-Slicing 등) | 드라이버가 지원하면 요청서에서 표현 |

DRA의 기본 흐름은 [조건으로 GPU 받기 (DRA)](../k8s/dra.mdx)에서 다룬다. 다음 레슨 [가속기를 조건으로 받기 (DRA 심화)](./accelerator-allocation.mdx)에서는 AI 워크로드가 GPU와 네트워크 카드를 조건으로 함께 받는 흐름을 본다.
