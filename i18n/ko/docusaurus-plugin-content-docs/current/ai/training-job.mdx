# 학습 작업이 모델이 되기까지

GPU는 여러 팀이 함께 쓴다. 학습·평가 Job을 바로 실행하지 않고 **대기열**에 넣어 두었다가, 팀에 배정된 GPU 쿼터가 비면 실행한다. 여기서는 Kueue를 예로 들어 Job이 대기하고, 실행되고, 산출물을 남기고, 모델 레지스트리에 버전으로 올라가기까지 따라간다.

## 바로 실행 vs 대기열

| | Job을 바로 실행 | Kueue 대기열 |
| --- | --- | --- |
| GPU가 모자랄 때 | 일부 Pod만 떠서 Pending으로 GPU를 붙잡는다 | Job 전체가 suspend로 기다린다 |
| 팀 간 공정성 | 먼저 만든 쪽이 차지한다 | 팀별 쿼터, 빌려 쓰기, 선점 |
| 대기 이유 확인 | Pod 이벤트를 하나씩 본다 | Workload 상태 메시지 |

더 읽을거리: [잡](https://kubernetes.io/ko/docs/concepts/workloads/controllers/job/) · [Kueue 개요](https://kueue.sigs.k8s.io/docs/overview/)
