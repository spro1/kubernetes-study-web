# 가속기 나눠 쓰기 (시분할·MPS)

작은 모델 하나가 GPU 한 장을 통째로 쓰면 대부분이 논다. DRA로 GPU를 받을 때는 장치 요청서의 설정에 **공유 방식(TimeSlicing 또는 MPS)** 을 적어 GPU 한 장을 여러 파드가 나눠 쓰게 할 수 있다. 공유 설정을 적지 않으면 요청서 하나가 GPU 한 장을 통째로 받는다. 여기서는 이것을 "없음"이라고 부른다. 여기서는 NVIDIA의 GPU용 DRA 드라이버를 예로 든다. GPU Operator로 MIG·시분할을 노드 단위로 설정하는 방식은 [GPU 나눠 쓰기](../feature/gpu-sharing.mdx)에 있다.

## 세 방식 비교

| 구분 | 없음 | 시분할 | MPS |
| --- | --- | --- | --- |
| 누가 나눠 쓰나 | 나누지 않음 | 같은 요청서를 가리키는 파드끼리 | 같은 요청서를 가리키는 파드끼리 |
| 나누는 방식 | 통째로 | 시간을 번갈아 | 상한을 정해 동시에 |
| 격리·보장 | 다른 파드 영향 없음 | 메모리 격리·성능 보장 없음 | 상한 안에서 동시 실행, 오류 격리는 약함 |

## 직접 확인해 보기

```bash
kubectl get resourceclaims -n <네임스페이스>            # 여러 파드가 함께 쓰는 이름 붙은 요청서 (3단계)
kubectl get resourceclaim <이름> -n <네임스페이스> -o jsonpath='{.status.reservedFor[*].name}'   # 이 요청서를 쓰는 파드
kubectl get resourceclaim <이름> -n <네임스페이스> -o jsonpath='{.spec.devices.config}'   # TimeSlicing 또는 MPS 설정
kubectl exec <파드> -- nvidia-smi                     # 예: NVIDIA. 함께 쓰는 GPU 메모리와 프로세스 (5단계)
kubectl describe quota -n <네임스페이스>                # 파드가 아니라 요청서 단위로 계산 (8단계)
```
