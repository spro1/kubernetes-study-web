## 어떤 검사가 무엇을 잡는가

| 위험 | 검사 | 도구 예 | 위치 |
|---|---|---|---|
| 직접 프롬프트 인젝션, 탈옥 | 프롬프트 공격 분류기 | Llama Prompt Guard 2, NeMo Guardrails 입력 레일 | 게이트웨이 또는 앱 |
| 문서·도구 출력 속 간접 인젝션 | 믿을 수 없는 내용에도 같은 분류기, 데이터 표시 | RAG·도구 단계의 프롬프트 공격 분류기 | 앱 |
| 모델로 보내지는 개인정보 | 호출 전에 찾아서 가리기 | Presidio, 정규식 규칙 | 게이트웨이 또는 앱 |
| 위험하거나 정책에 어긋난 내용 | 입력·출력에 안전 분류기 | Llama Guard 4 | 게이트웨이 또는 앱 |
| 답 속의 개인정보·비밀값 유출 | 출력 검사와 가리기 | Presidio, 비밀값 패턴 | 앱 또는 게이트웨이 |
| 깨진 구조화 출력 | 스키마 검증, 재시도 또는 안전한 실패 | JSON Schema, Guardrails AI 검증기 | 앱 |
| 권한 없는 도구 동작 | 도구 API의 권한 검사, 범위를 좁힌 자격 증명 | 내 API의 인가, 사람의 승인 | 도구 |
