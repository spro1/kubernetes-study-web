# 도구를 부르는 LLM 에이전트 서빙하기

에이전트는 모델이 도구를 요청하게 두고, 답이 나올 때까지 모델을 거듭 부르는 애플리케이션이다. 모델은 도구를 직접 실행하지 않는다. 도구 호출을 JSON으로 적을 뿐이고 실행은 **앱**이 하므로, 제한과 안전장치도 앱에 둔다.

## 에이전트 위험과 대책

| 위험 | 보이는 모습 | 대책 |
|---|---|---|
| 끝나지 않는 루프 | 같은 도구 호출이 반복되고 작업이 안 끝난다 | 작업당 최대 단계, 도구별 타임아웃, 작업 마감 |
| 비용·지연 증가 | 턴마다 늘어난 기록을 다시 보낸다 | 작업당 토큰 추적, 도구 결과 짧게, 프리픽스 캐시 |
| 권한이 지나친 도구 | 도구가 공용 관리자 자격 증명을 쓴다 | 사용자 범위, 되도록 읽기 전용, 도구마다 자격 증명 분리 |
| 코드·웹 도구 | 도구가 내부 서비스에 닿는다 | 비밀값 없고 외부 통신을 막은 샌드박스 |
| 프롬프트 인젝션 | 도구 결과에 지시문이 들어 있다 | 출력은 데이터로 다루기, 도구 권한 좁히기, 위험한 동작은 승인 |
| 원인 모를 실패 | 답이 틀렸는데 어느 단계인지 모른다 | 작업마다 트레이스 하나, 모델·도구 호출마다 스팬 하나 |
