## 직접 확인해 보기

```bash
kubectl get ingressclass                             # 쓸 수 있는 처리기와 기본 클래스
kubectl get ingress shop -o wide                     # CLASS, HOSTS, ADDRESS
kubectl describe ingress shop                        # 경로별 백엔드와 이벤트
kubectl get endpointslices -l kubernetes.io/service-name=api   # 백엔드 서비스가 파드를 무는지
kubectl get secret shop-tls -o jsonpath='{.type}'    # kubernetes.io/tls 인지
```
