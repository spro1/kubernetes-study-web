## 직접 확인해 보기

```bash
kubectl describe ingress -n shop                                  # 인그레스: 호스트·경로와 백엔드
kubectl get gateways.networking.istio.io,virtualservices -n shop  # 메시 길: 게이트웨이와 가상 서비스 짝
kubectl get namespace shop --show-labels                          # istio-injection=enabled 인지
kubectl get gatewayclass                                          # 게이트웨이 API 처리기
kubectl get gateways.gateway.networking.k8s.io,httproutes -n shop # 표준 Gateway와 라우트
```
