## 직접 확인해 보기

```bash
kubectl label namespace shop istio-injection=enabled   # 사이드카 자동 주입 켜기
kubectl get namespace -L istio-injection               # 어느 구획에 켜져 있는지
kubectl rollout restart deployment -n shop             # 기존 파드를 다시 만들어 사이드카 붙이기
kubectl get pods -n shop                               # READY 2/2 이면 프록시가 붙은 것
kubectl get peerauthentication -A                      # mTLS 모드(PERMISSIVE·STRICT)
```
