# 파드 크기 자동 조정 (VPA)

## 직접 확인해 보기

```bash
kubectl get vpa -A                                   # 걸린 VPA와 동작 모드
kubectl describe vpa <이름>                          # Recommendation(권장값)
kubectl get pod <파드> -o jsonpath='{.spec.containers[*].resources}'   # 실제 파드 값
kubectl get hpa -A                                   # 같은 대상에 HPA가 걸렸는지
```
