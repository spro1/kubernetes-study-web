# 네임스페이스와 리소스 쿼터

여러 팀이 클러스터 하나를 나눠 쓸 때는 쿠버네티스의 **네임스페이스(namespace — 클러스터 안의 구획)**와 **리소스 쿼터(resource quota — 구획별 자원 상한)**가 일한다. 구획을 나누고, 상한을 걸고, 상한을 넘는 파드가 거절되기까지 따라가 본다.

## 직접 확인해 보기

```bash
kubectl get namespaces
kubectl describe quota -n team-a          # Hard(상한)와 Used(사용량)
kubectl get limitrange -n team-a          # 기본 requests·limits
kubectl get events -n team-a | grep -i quota
kubectl auth can-i create resourcequotas -n team-a
```
