## 서비스 ipFamilyPolicy

| ipFamilyPolicy | ClusterIPs | 단일 스택 클러스터에서 | 흔한 용도 |
| --- | --- | --- | --- |
| SingleStack (기본값) | 첫 번째 서비스 대역이나 `ipFamilies`의 주소 체계에서 하나 | 동작함 | 기존 서비스, 아직 IPv6로 시험하지 않은 앱 |
| PreferDualStack | 클러스터가 듀얼 스택이면 둘 | 하나로 물러섬 | 앱이 두 주소 체계에서 다 들은 뒤의 대부분의 서비스 |
| RequireDualStack | 항상 둘 | 생성 실패 | 두 주소 체계 모두로 닿아야 하는 서비스 |

셀렉터가 없는 헤드리스 서비스에서 `ipFamilyPolicy`를 정하지 않으면 기본값은 RequireDualStack이다. `ipFamilies`의 첫 항목이 기본 주소 체계이고, 기존 서비스에서는 바꿀 수 없다.

## 직접 확인해 보기

```bash
kubectl get nodes -o jsonpath='{range .items[*]}{.metadata.name}{"  "}{.spec.podCIDRs}{"\n"}{end}'   # 주소 체계마다 파드 CIDR 하나
kubectl get pod <pod> -o jsonpath='{.status.podIPs}'                       # 듀얼 스택이면 항목 둘
kubectl get svc <svc> -o jsonpath='{.spec.ipFamilyPolicy} {.spec.ipFamilies} {.spec.clusterIPs}'
kubectl patch svc <svc> -p '{"spec":{"ipFamilyPolicy":"PreferDualStack"}}'   # 두 번째 주소 체계를 그 자리에서 더한다
kubectl run dns-test --rm -it --image=busybox:1.36 --restart=Never -- nslookup -type=AAAA <svc>.<namespace>.svc.cluster.local
kubectl exec <pod> -- ss -ltn       # 이미지에 ss가 있으면: 0.0.0.0:8080 = IPv4 만, [::]:8080 = IPv6 도
```
