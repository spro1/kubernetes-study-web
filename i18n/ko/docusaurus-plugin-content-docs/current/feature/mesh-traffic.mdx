## 직접 확인해 보기

```bash
kubectl get destinationrule api -o yaml      # subsets, trafficPolicy(부하 분산·연결 제한)
kubectl get virtualservice api -o yaml       # match(헤더), route weight, retries, timeout
kubectl edit virtualservice api              # 비율을 100 : 0으로 되돌리기
istioctl proxy-config routes deploy/web      # web 쪽 프록시가 받은 실제 규칙
```
