## 직접 확인해 보기

```bash
kubectl get pods -n istio-system -l istio=ingressgateway       # 입구 프록시가 떠 있는지
kubectl get gateways.networking.istio.io -n shop -o yaml       # hosts, port, selector, tls
kubectl get virtualservice -n shop -o yaml                     # gateways, hosts, route destination
kubectl get namespace shop --show-labels                       # istio-injection=enabled 인지
istioctl analyze -n shop                                       # 끊긴 고리 찾기
```
