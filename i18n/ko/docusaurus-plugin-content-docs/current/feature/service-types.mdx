## 직접 확인해 보기

```bash
kubectl get svc shop-svc -o wide                       # TYPE, CLUSTER-IP, EXTERNAL-IP, PORT(S), SELECTOR
kubectl get pods -l app=shop --show-labels             # 셀렉터에 맞는 파드가 있는지
kubectl get endpointslices -l kubernetes.io/service-name=shop-svc   # 대상 파드 주소가 비어 있지 않은지
kubectl get svc shop-svc -o yaml                       # type, selector, ports, sessionAffinity
```
