# GPU 나눠 쓰기

GPU는 비싸서 놀리지 말고 나눠 써야 한다. 쿠버네티스에서 NVIDIA GPU Operator를 쓰면 GPU 한 장을 **통째로(Pass-through)**, **하드웨어 칸막이로(MIG)**, **시간을 쪼개(Time-Slicing)** 나눠 쓰게 한다. 방식마다 무엇이 나뉘고 지표에 무엇이 보이는지 따라가 본다.

## 직접 확인해 보기

```bash
kubectl get pods -n gpu-operator                     # GPU Operator 구성요소 상태
kubectl describe node <gpu-node> | grep -i nvidia    # GPU 자원 이름·개수, MIG 레이블
kubectl get pods -A -o wide | grep -i gpu            # GPU 파드가 어느 노드에 떴는지
```
