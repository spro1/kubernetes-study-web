# CRD와 오퍼레이터

쿠버네티스 기본 자원에는 "데이터베이스 하나"나 "매일 밤 백업" 같은 개념이 없다. 그래서 새 자원 종류를 등록하고(CRD), 그 자원을 처리하는 프로그램(오퍼레이터)을 붙인다. Istio(서비스 메시), Velero(백업), NVIDIA GPU Operator 같은 도구 대부분이 이 구조 위에 서 있다. 아래 `Database`는 설명을 위한 예시 자원이다.

## 증상으로 거꾸로 찾기

| 증상 | 원인 후보 | 확인할 것 |
| --- | --- | --- |
| CR을 만들었는데 몇 시간째 status가 비어 있다 | 처리할 컨트롤러(오퍼레이터)가 없거나 멈춤 | 컨트롤러 파드 실행 여부, 로그, CR의 이벤트 |
| 도구를 새 버전으로 올렸는데 새 필드를 쓰면 저장이 거절된다 | Helm이 CRD를 갱신하지 않아 옛 스키마가 남음 | 도구 업그레이드 안내의 CRD 갱신 절차 |
| 도구를 지운 뒤 네임스페이스가 Terminating에서 끝나지 않는다 | CR의 파이널라이저를 치울 오퍼레이터가 먼저 지워짐 | 남은 CR의 finalizers |
| 백업 일정이 한꺼번에 사라졌다 | CRD 삭제로 그 종류의 CR이 모두 삭제됨 | 도구 제거·업그레이드 이력 |
