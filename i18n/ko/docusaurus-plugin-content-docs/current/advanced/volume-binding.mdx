## 오해와 사실

| 오해 | 사실 |
| --- | --- |
| PVC가 Pending이면 고장이다 | WaitForFirstConsumer에서는 파드가 생길 때까지 정상이다 |
| 로컬 볼륨은 빠르니 늘 좋다 | 노드 고장 때 파드가 다른 노드로 옮겨 가지 못한다 |
| 노드가 죽으면 볼륨이 바로 다른 노드에 붙는다 | RWO는 이전 노드에서 분리됐다는 확인을 기다린다 |
| RWO는 파드 하나만 쓸 수 있다는 뜻이다 | 노드 하나다. 같은 노드의 여러 파드는 함께 쓴다 |
| 볼륨 용량은 나중에 줄이면 된다 | 늘리기만 된다 |
| 스냅샷이 있으니 백업은 필요 없다 | 스냅샷은 같은 장비 안에 있어 장비 고장 때 함께 잃을 수 있다 |
