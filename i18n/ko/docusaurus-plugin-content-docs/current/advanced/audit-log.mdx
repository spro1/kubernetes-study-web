# 감사 로그

"어제 누가 운영 데이터베이스 비밀번호를 조회했나?" 이 질문에 답하려면 요청이 지나갈 때 기록이 남아 있어야 한다. 쿠버네티스 API 서버가 남기는 감사 로그(audit log)가 무엇을 어느 수준으로 기록하고, 어디로 보내 보관하는지 따라가 본다. 요청이 API 서버 안에서 거치는 관문은 [API 요청이 저장되기까지](./api-request-path.mdx)에서 먼저 본다.

## 기록 수준 한눈에

| 수준 | 남는 것 | 언제 쓰나 |
| --- | --- | --- |
| None | 남기지 않음 | 잦고 감사 가치가 없는 요청 |
| Metadata | 누가·언제·무엇에·어떤 동작을·결과 | 시크릿처럼 본문에 비밀이 있는 자원 |
| Request | 위 + 요청 본문 | 무엇을 바꾸려 했는지가 중요한 변경 요청 |
| RequestResponse | 위 + 응답 본문 | 꼭 필요한 대상만. 저장량이 크고 비밀이 남을 수 있다 |
