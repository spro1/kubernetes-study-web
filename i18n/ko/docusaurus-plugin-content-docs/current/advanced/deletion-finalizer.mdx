# 삭제는 생각보다 복잡하다

## 흔한 파이널라이저와 멈추는 경우

| 파이널라이저 | 무엇을 기다리나 | 오래 멈추는 경우 |
| --- | --- | --- |
| `kubernetes.io/pvc-protection` | 이 PVC를 쓰는 파드가 없어지기를 | 아직 PVC를 마운트한 파드가 살아 있다 |
| `kubernetes.io/pv-protection` | 이 PV에 연결된 PVC가 없어지기를 | PVC가 남아 있다 |
| 네임스페이스의 `kubernetes` | 네임스페이스 안 자원이 모두 지워지기를 | 안쪽 자원 중 하나가 파이널라이저로 멈췄다 |
| 각 도구가 붙이는 이름 | 해당 도구가 외부 자원을 정리하기를 | 그 도구의 컨트롤러가 이미 제거되었거나 멈췄다 |

## 직접 확인해 보기

```bash
kubectl get pvc -A -o custom-columns=NAME:.metadata.name,FINALIZERS:.metadata.finalizers   # PVC마다 붙은 pvc-protection
kubectl get <종류> <이름> -n <네임스페이스> -o jsonpath='{.metadata.deletionTimestamp} {.metadata.finalizers}'   # Terminating: 언제부터, 무엇을 기다리는지
kubectl get pod <파드> -o jsonpath='{.metadata.ownerReferences}'       # 이 파드의 주인
kubectl get namespace <네임스페이스> -o jsonpath='{.status.conditions}'   # 네임스페이스 삭제가 멈춘 이유
kubectl api-resources --verbs=list --namespaced -o name | xargs -n 1 kubectl get --show-kind --ignore-not-found -n <네임스페이스>   # 안쪽에 남은 자원
```
