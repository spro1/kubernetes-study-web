# 장애 실습

레슨은 어떻게 동작하는지 보여 준다. 실습은 직접 고치게 한다. 실습마다 일부러 고장 난 것을 만들어 두고, 실무에서처럼 원인을 찾아 고치는 것이 할 일이다.

## 실습 방법

1. **실습 클러스터를 한 번 만든다.** [노트북에 실습 클러스터 만들기](../basic/lab-cluster.mdx)를 따른다. 모든 실습이 그 kind 클러스터에서 돈다.
2. **준비 블록을 실행한다.** `lab-NN` 네임스페이스(예: `lab-06`)와 그 안의 고장 난 리소스가 만들어진다.
3. **증상을 읽고 살펴본다.** 살펴보기의 명령은 어디를 볼지 알려 줄 뿐 답은 알려 주지 않는다.
4. **힌트를 열기 전에 먼저 해 본다.** 힌트는 가벼운 것에서 거의 답인 것 순서다. 정답은 마지막에 열고, 스스로 찾은 것과 비교한다.
5. **확인하고 정리한다.** 네임스페이스를 지우면 실습이 만든 것이 모두 사라진다. 실습 10은 설치한 컨트롤러를 지우는 방법도 알려 준다.
