# kubectl debug로 실행 중인 파드 디버깅하기

파드가 이상하게 동작하는데 이미지에 셸이 없다. **kubectl exec → 임시 컨테이너 → 파드 복사본 → 노드 디버깅 파드** 순서로 따라가며, 각각 무엇을 볼 수 있고 무엇이 필요하며 무엇을 남기는지 본다.

## 어떤 방법으로 디버깅할까

| 상황 | 쓰는 것 | 볼 수 있는 것 | 남는 것 |
|---|---|---|---|
| 컨테이너가 돌고 셸이 있다 | `kubectl exec -it <pod> -- sh` | 그 컨테이너 안의 모든 것 | 없음 |
| 컨테이너는 돌지만 이미지에 셸이 없다(distroless) | `kubectl debug -it <pod> --image=busybox:1.36 --target=<container>` | 파드 네트워크. `--target`을 주면 컨테이너 프로세스와 `/proc/<pid>/root` | 파드가 바뀔 때까지 Terminated 임시 컨테이너 |
| 컨테이너가 시작하자마자 죽는다 | `kubectl logs <pod> --previous` 다음에 `kubectl debug <pod> -it --copy-to=<name> --container=<c> -- sh` | 명령이나 이미지(`--set-image`)를 바꾼 파드 복사본 | 지울 때까지 복사본 파드 |
| 노트북에서 앱을 불러 봐야 한다 | `kubectl port-forward pod/<pod> 8080:8080` | 파드 네트워크의 포트 하나 | 멈추면 없음 |
| 노드 문제(디스크, 네트워크, 프로세스) | `kubectl debug node/<node> -it --image=ubuntu` | 호스트 PID·네트워크·IPC 네임스페이스, `/host` 의 호스트 파일 | 지울 때까지 node-debugger 파드 |
| `Forbidden ... pods/ephemeralcontainers` | `pods/ephemeralcontainers` 에 `patch`, `update` 권한을 준다 | — | — |

## 직접 확인해 보기

```bash
kubectl run demo --image=registry.k8s.io/pause:3.10 --restart=Never   # 셸이 없는 이미지
kubectl exec -it demo -- sh                                # 실패: 이미지에 sh가 없다
kubectl debug -it demo --image=busybox:1.36 --target=demo  # 임시 컨테이너. ps 를 쳐 본다
kubectl get pod demo -o jsonpath='{.spec.ephemeralContainers[*].name}{"\n"}'   # spec에 남아 있다
kubectl debug demo -it --copy-to=demo-debug --image=busybox:1.36 --share-processes   # 디버그 컨테이너를 넣은 복사본
kubectl debug node/$(kubectl get pod demo -o jsonpath='{.spec.nodeName}') -it --image=ubuntu   # ls /host 를 쳐 본다
kubectl auth can-i patch pods/ephemeralcontainers         # 권한이 있는가?
kubectl get pods | grep -E 'debug|node-debugger'          # 남은 것
kubectl delete pod demo demo-debug                        # 뒷정리 (node-debugger-... 파드도)
```
