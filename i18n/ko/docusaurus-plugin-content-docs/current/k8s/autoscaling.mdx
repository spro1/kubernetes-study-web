## HPA가 기대처럼 움직이지 않을 때

| 증상 | 확인할 것 |
| --- | --- |
| 사용률이 `<unknown>`으로 나온다 | metrics-server가 동작하는지, 파드에 자원 요청량(requests)이 적혀 있는지 |
| 필요 파드 수는 늘었는데 파드가 Pending이다 | 노드 남은 자원, 네임스페이스 쿼터 |
| 부하가 줄었는데 파드가 그대로다 | 스케일 인 대기 시간(안정화 시간)이 지났는지, 최소 레플리카 수 |
