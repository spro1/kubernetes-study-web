## 멈춘 단계별 증상

| 멈춘 단계 | kubectl get 으로 보이는 모습 | 확인할 곳 |
| --- | --- | --- |
| 3. 디스크 생성 | PVC가 계속 `Pending` | PVC 이벤트: 스토리지 클래스 이름 오타, 프로비저너 미설치, 용량 부족, 지원하지 않는 접근 모드 |
| 6. 노드 연결 | 파드가 `ContainerCreating`에 머문다 | 파드 이벤트의 `FailedAttachVolume`. 볼륨이 아직 다른 노드에 붙어 있는 경우가 많다 |
| 6. 마운트 | 파드가 `ContainerCreating`에 머문다 | 파드 이벤트의 `FailedMount`(권한, 파일 시스템 오류, NFS 서버 접근 불가) |
