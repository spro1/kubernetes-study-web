# 설정과 비밀값 (ConfigMap·Secret)

로그 수준이나 DB 비밀번호 같은 값은 이미지 안에 넣지 않고 따로 보관한다. 그 값이 어떻게 파드에 들어가고, 값을 바꾸면 언제 반영되는지 따라가 본다.

## 환경변수와 파일 마운트 비교

| 구분 | 환경변수 | 파일 마운트 |
| --- | --- | --- |
| 앱이 읽는 때 | 프로그램이 시작될 때 한 번 | 지정한 경로의 파일을 읽을 때 |
| ConfigMap·Secret 값을 바꾸면 | 파드를 다시 띄워야 반영된다 | 파일은 잠시 뒤 자동으로 바뀐다. 앱이 파일을 다시 읽어야 적용된다 |
| 어울리는 값 | 짧은 값 몇 개 | 설정 파일 통째, 인증서 |
