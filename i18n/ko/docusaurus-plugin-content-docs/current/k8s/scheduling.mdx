## 배치 규칙 한눈에

| 규칙 | 방향 | 하는 일 | 예 |
| --- | --- | --- | --- |
| 요청량(`requests`) | 스케줄러가 노드를 거른다 | 요청량 합계만큼 여유가 없는 노드를 뺀다 | CPU 1코어 요청 → 여유 0.5코어 노드 제외 |
| 테인트·톨러레이션 | 노드가 파드를 거른다 | 표시를 견디는 파드만 받는다 | GPU 노드에 일반 파드가 못 오게 |
| 노드 셀렉터·노드 어피니티 | 파드가 노드를 고른다 | 레이블이 맞는 노드로만 간다 | `gpu: "true"` 노드에만 |
| 파드 안티 어피니티 | 파드가 다른 파드를 피한다 | 같은 앱 복제본을 서로 다른 노드에 둔다 | web 복제본을 노드마다 하나씩 |

## 직접 확인해 보기

```bash
kubectl describe pod <파드>                           # Events: 0/3 nodes are available: ...
kubectl describe node <노드> | grep -A 8 'Allocated resources'   # 실사용이 아니라 requests 합
kubectl get nodes -o custom-columns=NAME:.metadata.name,TAINTS:.spec.taints   # 노드 테인트
kubectl get nodes --show-labels                      # nodeSelector가 맞춰 볼 라벨
kubectl get pods -o wide                             # 복제본마다 놓인 노드
```
