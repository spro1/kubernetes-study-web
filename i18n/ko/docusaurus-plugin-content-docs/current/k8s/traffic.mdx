## 접속이 안 될 때 확인 순서

| 순서 | 확인할 것 | 흔한 원인 |
| --- | --- | --- |
| 1 | 도메인이 로드밸런서 주소로 연결되는가 | DNS 미등록, 로드밸런서 주소 변경 |
| 2 | Ingress 규칙의 host·path가 맞는가 | 오타, 다른 Ingress와 규칙 충돌 |
| 3 | Service가 가리키는 레이블과 포트가 맞는가 | 레이블 불일치로 대상 파드 0개 |
| 4 | Ready 파드가 하나 이상 있는가 | 준비 상태 검사 실패, 파드 전부 재시작 중 |

## 직접 확인해 보기

```bash
kubectl get ingress -A                               # HOSTS와 로드밸런서 ADDRESS
kubectl describe ingress <이름>                      # 호스트·경로 → 서비스 규칙
kubectl get svc <서비스> -o wide                    # SELECTOR와 포트
kubectl get endpointslices -l kubernetes.io/service-name=<서비스> -o yaml   # 파드별 conditions.ready
kubectl get pods -o wide                             # 파드별 READY
```
