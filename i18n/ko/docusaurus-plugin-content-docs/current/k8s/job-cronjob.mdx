# 한 번 돌고 끝나는 일 (Job·CronJob)

월간 보고서를 만드는 프로그램은 계속 떠 있을 필요가 없다. 한 번 돌고 끝나면 된다. 이런 일을 맡는 Job과, 일정마다 Job을 찍어 내는 CronJob을 따라가 본다.

## 동시 실행 정책 한눈에

| `concurrencyPolicy` | 앞 실행이 안 끝났을 때 | 어울리는 일 |
| --- | --- | --- |
| `Allow` (기본값) | 새 Job을 만들어 함께 돌린다 | 실행끼리 서로 영향이 없는 일 |
| `Forbid` | 이번 일정을 건너뛴다 | 같은 데이터를 고쳐서 겹치면 안 되는 일 |
| `Replace` | 돌던 Job을 지우고 새 Job으로 바꾼다 | 늘 최신 실행 하나만 의미 있는 일 |

## 직접 확인해 보기

```bash
kubectl get cronjob -A                               # SCHEDULE과 LAST SCHEDULE
kubectl create job try-job --image=busybox -- sh -c 'echo done'   # 연습용 Job
kubectl get job try-job                              # COMPLETIONS가 1/1이 된다
kubectl logs job/try-job                             # 로그는 Job이 만든 파드에 있다
kubectl delete job try-job                           # 정리(파드도 함께 지워진다)
```
