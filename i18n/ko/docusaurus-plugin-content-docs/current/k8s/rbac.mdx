## RBAC를 이루는 네 가지

| 이름 | 하는 일 | 범위 |
| --- | --- | --- |
| `Role` | 어떤 자원에 어떤 동작(get·list·delete 등)을 허용할지 모은 권한 묶음 | 네임스페이스 하나 |
| `ClusterRole` | 같은 권한 묶음이지만 노드 같은 클러스터 범위 자원까지 다룰 수 있다 | 클러스터 |
| `RoleBinding` | 권한 묶음을 사용자·그룹·서비스 어카운트에 연결한다 | 네임스페이스 하나 |
| `ClusterRoleBinding` | ClusterRole을 클러스터 전체에 걸쳐 연결한다 | 클러스터 |

더 읽을거리: [RBAC 인가 사용](https://kubernetes.io/docs/reference/access-authn-authz/rbac/) · [네임스페이스](https://kubernetes.io/ko/docs/concepts/overview/working-with-objects/namespaces/)
