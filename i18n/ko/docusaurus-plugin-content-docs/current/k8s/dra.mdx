# 조건으로 GPU 받기 (DRA)

지금까지 쿠버네티스는 GPU를 "몇 장"으로만 요청했다. **동적 리소스 할당(DRA, Dynamic Resource Allocation)**은 "메모리 40GB 이상인 GPU 한 장"처럼 **조건으로** 요청하는 방식이다. 핵심 API는 쿠버네티스 1.34에서 정식 기능이 되었다. 요청이 장치로 바뀌기까지 따라가 본다.

## 기존 방식과 DRA 비교

| 구분 | 기존(장치 플러그인) | DRA |
| --- | --- | --- |
| 요청 방법 | 개수만 (`nvidia.com/gpu: 1`) | 종류 + 조건 (메모리 40GB 이상 등) |
| 장치 정보 | 노드에 "몇 개 있다"만 알림 | 드라이버가 장치별 속성까지 목록으로 올림 |
| 누가 고르나 | 노드의 kubelet이 남은 장치 중 아무거나 | 스케줄러가 조건에 맞는 장치를 골라 기록 |
| 쿠버네티스 상태 | 계속 쓰인다 | 핵심 API는 1.34에서 정식, 부가 기능은 이후 버전에서 차례로 정식 |
