## 증상으로 멈춘 곳 찾기

| 앱에서 보이는 증상 | 멈춘 곳 | 흔한 원인 |
| --- | --- | --- |
| 이름을 찾을 수 없음 (host not found) | DNS 조회 | 서비스 이름 오타, 다른 네임스페이스 서비스를 짧은 이름으로 부름 |
| 이름 조회가 응답 없이 실패, IP로는 접속됨 | DNS 서버 | CoreDNS 장애, 네트워크 정책이 DNS(53번 포트) 조회를 막음 |
| 이름은 찾았는데 접속 실패 | 서비스 → 파드 | 셀렉터와 파드 레이블 불일치로 대상 파드 0개, 포트 불일치 |
