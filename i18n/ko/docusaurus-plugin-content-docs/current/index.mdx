# 전체 레슨

글로 읽으면 헷갈리는 흐름을 **한 단계씩 움직이는 다이어그램**으로 따라간다. 레슨 하나는 10분 안팎이고, **다음**을 누를 때마다 구성요소가 나타나고 요청이 흐른다. **▶ 자동 진행**을 켜면 손을 떼고 영상처럼 볼 수도 있다.

처음이라면 위에서부터 순서대로, 익숙하다면 궁금한 흐름부터 골라 보자.

## 쿠버네티스는 이렇게 움직인다

쿠버네티스 안에서 요청과 상태가 어떻게 오가는지 따라간다. 순서대로 보면 앞 레슨의 개념이 다음 레슨의 바탕이 된다.

## 레슨 보는 법

| 조작 | 방법 |
| --- | --- |
| 다음·이전 단계 | 오른쪽 패널의 버튼, 또는 레슨 영역을 한 번 누른 뒤 <kbd>←</kbd> <kbd>→</kbd> |
| 원하는 단계로 이동 | 아래 단계 타임라인의 번호 |
| 자동 진행 | 다이어그램 위 **▶ 자동 진행** 버튼, 또는 <kbd>A</kbd> |
| 애니메이션 다시 보기·멈춤 | 다이어그램 위 버튼, 또는 <kbd>R</kbd> · <kbd>P</kbd> |
| 선 색 | 파랑 = 요청, 보라 = 응답·보고, 청록 점선 = 지켜보기(watch) |

시스템 설정에서 '동작 줄이기'를 켜 두면 움직이는 점 없이 선과 설명만 보인다.
