# 전체 레슨

글로 읽으면 헷갈리는 흐름을 **한 단계씩 움직이는 다이어그램**으로 따라간다. 레슨 하나는 10분 안팎이다. **다음**을 누를 때마다 구성요소가 나타나고 요청이 흐른다. **▶ 자동 진행**을 켜면 영상처럼 볼 수도 있다.

트랙은 쉬운 것부터 어려운 것 순서다. 처음이라면 위에서부터, 익숙하다면 궁금한 흐름부터 골라 보자. 끝낸 레슨에는 ✓가 붙는다.
